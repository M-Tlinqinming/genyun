# 企业资料模板

`intake-template-2026.11.xlsx` 就是客户在任务页下载的「资料模板」，模板版本「2026.11」（写在「填写说明」页 B2）。客户填好后整份上传，传上来的那份叫「资料表格」（用词见 `docs/review-2026-11-15/04-用词表.md` 7.8）。

- 来源：11-14 业务方确认的「2026.11 修正版」。入库前只去掉了文件属性里的「最后修改人」，表格内容、格式、下拉选项一格没动。
- 换模板：要同时改版本号、这份说明和解析代码。客户用旧版模板上传时怎么提示，见 Paper 12 页「用的是旧版模板」那块板。
- Docker 镜像会把 `apps/api/content` 整个打包进去，下载接口直接读这个文件就行。

## 七张工作表

| 工作表 | 读取位置 |
|---|---|
| 填写说明 | 只给客户看，不读 |
| 企业信息 | 第 3–28 行：A 列字段名，B 列填写内容，C 列提示。B14「是否位于园区」、B19「厂中厂」是「是 / 否」下拉 |
| 建筑与场所 | 建筑：表头第 4 行，数据第 5–17 行（A 名称、B 层数、C 建筑面积、D 结构类型、E 耐火等级、F 用途）。场所：第 21–32 行（A 场所名已预置，B 有 / 没有，C 补充说明） |
| 生产与设备 | B2（合并到 G2）：生产工艺一句话。设备：表头第 6 行，数据第 7–26 行（A 名称、B 规格型号、C 数量、D 单位、E 部门或地点、F 状况、G 备注）。特种设备：第 30–35 行（A 类别已预置：油库、储罐、压力容器、锅炉、压力管道、其他；B 有 / 没有；C 介质；D 数量或储存量；E 单位；F 主要参数；G 位置；H 提示） |
| 原辅料与危化品 | 表头第 4 行，数据第 5–44 行（A 类型：原辅料 / 气瓶，空着按原辅料；B 名称；C CAS 号；D 年用量；E 最大存放量；F 单位；G 存放位置；H 气瓶规格（升）） |
| 应急组织 | B2：24 小时值班电话。小组：表头第 6 行，第 7–28 行（A 小组名称已预置，B 应急职务，C 姓名，D 职务或岗位，E 手机）：第 7 行总指挥、第 8 行副总指挥；抢险救灾组、综合保障组、通讯联络组、医疗救护组、警戒疏散组的组长分别在第 9、13、17、21、25 行，每组下面 3 行组员。周边单位：表头第 32 行，第 33–37 行（A 类型已预置，B 名称，C 联系电话，D 备注） |
| 应急资源 | 物资：第 4–17 行（A 名称，前 8 行已预置：灭火器、室内消防栓、应急照明灯、疏散指示标志、急救药箱、防毒面具 / 空气呼吸器、安全绳、应急沙袋；B 数量，C 位置，D 保管人，E 电话，F 状态）。急救药箱药品：第 22–31 行（A 药品，B 数量，C 单位）。第 35–42 行 B 列依次是：消防水池有没有、容量（m³）、位置、自有车辆有没有、数量、停放位置、联系人、电话 |

客户可能在表尾插行，读数据行时要读到表尾空行为止，不能只读到上面写的最后一行。

## 必填（客户端提交前拦）

模板「填写说明」原话：带红色 * 且黄色底纹的格子必须填，缺了无法提交。必填共 20 项：18 项在本表，另外 2 项是两张图（总平面布置图、紧急疏散示意图）。消防设施布置图有就传，没有可以不传。

黄色底纹的格子：

| 工作表 | 格子 |
|---|---|
| 企业信息 | B3 企业名称、B12 生产场所地址、B14 是否位于园区、B19 厂中厂、B21 主要产品、B22 员工人数、B25 安全生产主管负责人、B26 联系人、B27 联系人手机 |
| 建筑与场所 | 第 1 栋建筑的 A5 名称、B5 层数、C5 建筑面积 |
| 生产与设备 | B2 生产工艺一句话；第 1 台设备的 A7 名称、C7 数量 |
| 原辅料与危化品 | 第 1 行的 B5 名称、E5 最大存放量、F5 单位、G5 存放位置 |
| 应急组织 | B2 值班电话；总指挥 C7 / E7、副总指挥 C8 / E8；前三组组长 C9 / E9、C13 / E13、C17 / E17（姓名 / 手机） |
| 应急资源 | B4 灭火器数量 |

- 医疗救护组、警戒疏散组的组长（第 21、25 行）不是黄色格：100 人以下只填前 3 个组，100 人以上或有危险化学品 5 个组都要填（表里第 5 行的说明）。
- 这些格子怎么数成 18 项、缺项提示怎么写，以 Paper 03 页「字段对照」FM01 和 12 页上传后的几块板为准。
- 急救药箱药品不必填：客户填了按客户的，没填按常规配置写进预案（11-14 定）。常规配置就是「应急资源」表第 20 行写的 7 样：纱布绷带 2 卷、医用棉签 2 包、脱脂棉球 2 包、碘伏消毒液 1 瓶、烫伤膏 1 盒、红花油 1 瓶、清凉油 1 瓶。
