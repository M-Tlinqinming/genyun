# 厂内车辆致害事故现场处置方案

## 事故风险描述

（1）事故类型：厂区内机车、运货车辆、私家车辆、外来车辆及职工电动车等在行驶过程中，如果个别车辆车况不良，造成刹车制动时摩擦系数下降，制动距离变长，或产生横滑，或因风、雨、雾等自然环境造成视线不良，驾驶员状态不佳操作不当、无证驾驶；或因厂区路面不平整，沟、池、坑洞无护拦、盖板、警示标志、厂区内人员未按规定行走等，均有可能导致厂内车辆致害事故。车辆出入库、行驶过程中，操作不当、无证驾驶、急转弯加速、不按道行驶等，亦可造成厂内车辆致害事故。

（2）事故区域：公司停车场、卸货区、仓库等厂区内有车辆运行的场所。

（3）事故基本征兆及条件：车辆存在缺陷，如刹车失灵、转向灯损坏等；场地存在缺陷，如路面湿滑、路面无限速牌等；驾驶员不安全行为，如酒后驾驶、精力不集中、无证驾驶等。

（4）事故可能造成的危害程度：伤亡、残疾、重伤、某些器官功能性失常或次生事故的发生等。

## 应急工作职责

### 应急组织形式及人员

由现场班组长和现场员工组成。有现场班组长的，现场班组长为现场负责人；无现场班组长的，由现场职务最高的员工或对事发区域负有安全责任的员工为现场负责人。

### 主要职责

**现场负责人职责：**

（1）无论在任何时候发生事故，现场负责人首先进入指挥岗位，做好应急处置工作，并安排将情况报告总指挥或副总指挥。

（2）估算事故的严重性及危害程度，现场应急力量是否有足够的能力进行处理，决定是否报告总指挥或副总指挥启动综合应急预案。

（3）如能有足够的人力物力处理事故，必须迅速调动相应的人力物力展开应急救援工作。

（4）如明确事故属于现场处置力量难以控制或人员难以救护性质的，则及早采取有效措施后，安排将重要物资、人员撤离现场到安全地带。

现场员工职责：听从现场负责人的指挥，进行应急处置及现场急救等工作。

## 应急处置

### 排险、控险应急处置措施

如果有车辆压住伤者，应立即用物品将四轮固定住，用车上千斤顶将车辆顶起，将伤者从车辆下解脱出来；如伤者被变形的车辆挤压，应用千斤顶、撬棍等将挤压部位扩张，把伤者从挤压部位解脱出来。如果发现车辆有漏油现象，应疏散无关人员，禁止点火源出现。

### 医疗救护应急处置措施

（1）不要轻易移动受伤者，保持其呼吸道通畅；

（2）有出血时，应有效止血，包扎伤口；

（3）如果发生骨折，用双手稳定及承托受伤部位，限制骨折处活动并设置软垫，用绷带、夹板或替代品妥善固定伤肢；

（4）发生断指（肢）应立即止血，尽可能将断指（肢）冲洗干净，用消毒敷料袋包好，放入装有冷饮的塑料袋内，将断指（肢）与伤者立即送往医院；

（5）如果伤者出现呼吸或心跳停止，应进行心肺复苏急救。

### 报警电话及报警内容

（1）电话：公司 24 小时值班电话 `{{COMPANY_24H_PHONE}}`；火灾报警 119；三警合一报警 110；急救中心 120。

（2）应报告以下内容：报警单位名称、发生事故的时间、地点、事故的类型、发展和蔓延情况、现场处置和控制情况、引起的厂内车辆致害及人员伤亡等内容。

## 注意事项

（1）受伤者伤势严重，不要轻易移动伤者，去除身上的用具和口袋中的硬物，注意不要让伤者再受到挤压；

（2）如上肢受伤将其固定于躯干，如下肢受伤将其固定于另一健肢。应垫高伤肢，消除肿胀。如上肢已扭曲，可用牵引法将上肢沿骨骼轴心拉直，但若拉伸时引起伤者剧痛或皮肤变白，应立即停止；

（3）如果伤口中已有赃物，不要用水冲洗，不要使用药物，也不要试图将裸露在伤口外的断骨复位，应在伤口上覆盖灭菌纱布，然后进行适度的包扎、固定；

（4）若发现窒息者，应及时解除其呼吸道梗塞和呼吸机能障碍，应立即解开伤员衣领，消除伤员口鼻、咽喉部的异物、血块、分泌物、呕吐物等；

（5）防止车辆移动，发生再次伤人事故。
