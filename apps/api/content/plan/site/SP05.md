# 容器爆炸事故现场处置方案

## 事故风险描述

（1）事故类型：公司生产涉及压缩空气罐，气瓶，因罐体老化、安全附件失灵，维护保养不当、员工违规操作等超压导致容器爆炸，同时爆炸产生的高温将可能引燃周围可燃易燃物。

[[if:expertArea]]
（2）事故区域：{{HAZARD_AREA}}。
[[endif]]
[[if:!expertArea]]
（2）事故区域：压缩机房。
[[endif]]

（3）事故基本征兆及条件：员工违规操作，容器裂纹或严重锈蚀；安全阀自动泄压，压力表指针指示超压等；

（4）事故可能造成的危害程度：可能导致人员伤亡、损坏设备设施、厂房等。

## 应急工作职责

### 应急组织形式及人员

由现场班组长和现场员工组成。无现场班组长的，由现场职务最高的员工或对事发区域负有安全责任的员工为现场负责人。

### 主要职责

**现场负责人职责：**

（1）无论在任何时候发生事故，现场负责人首先进入指挥岗位，做好应急处置工作，并安排将情况报告总指挥或副总指挥；

（2）估算事故的严重性及危害程度，现场应急力量是否有足够的能力进行处理，决定是否报告总指挥或副总指挥申请应急响应；

（3）如能有足够的人力物力处理事故，必须迅速调动相应的人力物力展开应急救援工作；

（4）如明确事故属于现场处置力量难以控制或人员难以救护性质的，则及早安排将重要物资、人员撤离现场到安全地带。

**现场应急救援人员的职责：**

现场应急人员的主要职责是听从现场负责人的指挥，进行应急处置及现场急救等工作。

## 应急处置

### 应急处置措施

**1）常规处置**

（1）立即疏散周围员工到安全区域以躲避冲击波，并防止烧、烫伤；

（2）切断空气压缩机电源，让空气压缩机停止运行；

（3）打开安全阀、堵头、阀门进行泄压；

（4）打开门窗通风，查找泄漏源堵漏；将周围可燃、易燃物迅速隔离；

### 医疗救护措施

（1）不要轻易移动受伤者，保持其呼吸道通畅；

（2）有出血时，应有效止血，包扎伤口；

（3）如果发生骨折，用双手稳定及承托受伤部位，限制骨折处活动并设置软垫，用绷带、夹板或替代品妥善固定伤肢；

（4）发生断指（肢）应立即止血，尽可能做到将断指（肢）冲洗干净，用消毒敷料袋包好，放入装有冷饮的塑料袋内，将断指（肢）与伤者立即送往医院；

（5）如果伤者出现呼吸或心跳停止，应进行心肺复苏急救。

### 报警（电话）及报警内容

（1）电话：公司 24 小时值班电话 `{{COMPANY_24H_PHONE}}`；火灾报警 119；三警合一报警 110；急救中心 120。

（2）应报告以下内容：报警单位名称、发生事故的时间、地点、事故的类型、发展和蔓延情况、现场处置和控制情况、引起的容器爆炸及人员伤亡等内容。

## 注意事项

（1）受伤者伤势严重，不要轻易移动伤者；

（2）抢救伤员时，必须配戴好防自身的防护用品；

（3）如有起火，在没有采取堵漏措施前，应保持稳定燃烧；

（4）在未切断压缩机电源，未采取泄压措施前，任何人不得进入现场。

（5）抢险人员必须佩戴好个人防护用品进入危险场所进行抢险和救护。（6）实施抢险救援时应先救人再实施其他抢险。

（7）现场救护与抢险相结合，如没有相应个人防护用品，不得盲目抢险和救护。

（8）现场施救人员应具备相应知识和能力，确保抢险和救治得体有效（9）设立警戒区防止无关人员进入危险区。
