# 起重致害（起重机）事故现场处置方案

## 事故风险描述

（1）事故类型：起重致害是指从事起重作业时引起的伤害事故，本方案适用于行车（桥式起重机）、电动葫芦、塔吊、门式起重机等起重机类作业引起的事故。**电梯类起重致害事故按 SP08a 起重致害（电梯）事故现场处置方案处置，本方案不重复覆盖电梯场景。** 起重机作业过程中，因吊钩、钢丝绳、吊具失效，超载吊运，违章指挥，吊物捆绑不牢，行走轨道偏移、限位失灵等原因，可能导致吊物坠落、起重机倾覆、被吊物夹挤撞击等人身伤害或设备损坏事故。

（2）事故区域：行车作业车间、塔吊覆盖区域、装卸作业区、电动葫芦吊运作业面、门式起重机轨道及堆场区域等所有起重作业场所。

（3）事故基本征兆及条件：钢丝绳出现断丝、磨损、变形、扭结，未及时更换；吊钩衬套、防脱钩装置、限位器、超载限制器等安全保护装置失效或被人为短接；吊物捆绑不牢、重心偏移、超出额定载荷；起重机司机无证或证件过期、违章操作（斜拉斜吊、强制操作限位、吊物上方有人通过等）；信号工指挥不清或地面无人指挥；轨道沉降、地基松软导致起重机倾覆；恶劣天气（强风、大雨）下违规作业。

（4）事故可能造成的危害程度：可能造成现场作业人员被吊物砸伤、夹挤致重伤甚至死亡；起重机倾覆可造成多人伤亡和厂房、设备的重大财产损失；伴随高空坠落、机械致害、电气事故等次生事故。

## 应急工作职责

### 应急组织形式及人员

由现场班组长、起重机司机（持证）、信号工和现场员工组成。无现场班组长的，由现场职务最高的员工或对事发区域负有安全责任的员工为现场负责人。

### 主要职责

**现场负责人职责：**

（1）无论在任何时候发生事故，现场负责人首先进入指挥岗位，做好应急处置工作，并安排将情况报告总指挥或副总指挥。

（2）估算事故的严重性及危害程度，现场应急力量是否有足够的能力进行处理，决定是否报告总指挥或副总指挥申请应急响应。

（3）如能有足够的人力物力处理事故，必须迅速调动相应的人力物力展开应急救援工作。

（4）如明确事故属于现场处置力量难以控制或人员难以救护性质的，则及早安排将重要物资、人员撤离现场到安全地带，及早拨打"120"请求救护。

**起重机司机职责（持证）：**立即停止起升、运行、回转等一切动作，关闭主电源开关；保持吊物在原位悬挂稳定，未经现场负责人确认安全前不得擅自下放或移动吊物；配合应急处置人员评估吊物及起重机本体稳定性。

**信号工职责：**立即发出停车信号，疏散吊物影响范围内的所有人员；协助现场负责人警戒事故区域。

**现场应急救援人员职责：**听从现场负责人的指挥，进行应急处置及现场急救等工作。

## 应急处置

当发生起重机致害事故后，抢救重点是迅速使受伤者脱离危险区，避免吊物或起重机本体进一步坠落、倾覆造成二次伤害；同时集中现场的人力、物力和设备，尽快把受伤者抬出来并立即抢救。

### 现场应急处置措施

（1）紧急停机：起重机司机或现场任一人员发现险情，立即按下急停按钮、切断起重机主电源；信号工同步发出停车信号，制止其他起重作业。

（2）划定隔离区：以吊物正下方及起重机本体倾覆方向为重点，向外延伸至少 5m（重型吊物或塔吊倾覆场景延伸至 10m 以上）划定警戒线，禁止无关人员进入；如吊物悬挂不稳，警戒区扩展至吊物可能坠落的全部覆盖范围。

（3）受伤人员脱困：由经过培训的应急人员在确认吊物及起重机稳定后进入隔离区，迅速将伤员转移至安全区域；如伤员被吊物压住，应使用千斤顶、撬棍等工具配合多人协作小心移除压迫物，严禁强行拖拽以防加重伤情。

（4）吊物处置：在专业人员（起重机司机或维修人员）评估稳定性后，使用备用起重设备或人工搭设支撑，将悬挂吊物缓慢卸载至地面安全位置；严禁在事故起重机本体未确认安全前继续使用该设备进行卸载。

（5）现场急救：参照下列要点处置——
1）有出血时，应有效止血、包扎伤口；
2）如果发生骨折，用双手稳定及承托受伤部位，限制骨折处活动并设置软垫，用绷带、夹板或替代品妥善固定伤肢；搬动伤员时勿使伤处移位、扭曲、震动；
3）发生断指（肢）应立即止血，尽可能将断指（肢）冲洗干净，用消毒敷料袋包好，放入装有冷饮的塑料袋内，与伤者一并立即送往医院；
4）对失去知觉者，宜清除口鼻中的异物、分泌物、呕吐物，将伤员置于侧卧位以防窒息；
5）如果伤者出现呼吸或心跳停止，应立即施行人工呼吸和胸外心脏按压，并速送医院。

（6）设备检查：事故起重机在专业检验合格前不得继续使用；保护事故现场，待安全监管部门或起重机检验机构调查取证。

## 注意事项

（1）严禁在悬挂吊物下方或起重机倾覆方向停留、通行；伤员脱困前必须先确认吊物与起重机本体稳定。

（2）非持证人员不得操作起重机；事故起重机的复位、卸载、移动等动作必须由持证司机或维修人员实施。

（3）抢救受伤人员（特别是重伤人员），一定要在现场或附近就地急救，切忌盲目长途护送到医院，以免延误抢救时间。

（4）防止起重物二次坠落：在起重机本体倾覆或吊物悬挂不稳的情况下，未经稳定加固前严禁攀爬起重机或对吊物进行抽绳、解扣等操作。

（5）险情发生至现场恢复期间，应封锁现场，防止无关人员进入发生意外；事故起重机经检验合格前一律停用。

（6）救助人员要服从指挥，统一行动；现场救护与抢险相结合，先救人再实施其他抢险。
