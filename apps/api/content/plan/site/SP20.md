# 可燃液体蒸气爆炸事故现场处置方案

## 事故风险描述

生产过程中擦拭使用的挥发性化学品，由于人为事故、突发事件，若化学物品泄漏，腐蚀线路、产生高温，遇明火、火花，引发可燃液体蒸气爆炸、中毒。

事故区域：生产车间。

（3）事故基本征兆及条件：易燃物品遇热源、电气机械火花、静电火花或人为事故、突发事件、交通事故等。

（4）事故可能造成的危害程度：人员伤亡、烧伤、损坏设车辆、交通堵塞等。

## 应急工作职责

### 应急组织形式及人员

由现场班组长和现场员工组成。无现场班组长的，由现场职务最高的员工或对事发区域负有安全责任的员工为现场负责人。

运输过程由现场驾驶员、押运员组成。由驾驶员对事发区域负有安全责任的员工为现场负责人。

### 主要职责

**现场负责人职责：**

（1）无论在任何时候发生事故，现场负责人应首先进入指挥岗位，做好应急处置工作，并将情况报告总指挥或副总指挥。

（2）估算事故的严重性及危害程度，现场应急力量是否有足够的能力进行处理，决定是否报告总指挥或副总指挥申请外部救援力量支援。

（3）如能有足够的人力物力处理事故，必须迅速调动相应的人力物力展开应急救援工作。

（4）如明确事故属于现场处置力量难以控制或人员难以救护性质的，则及早安排将重要物资、人员撤离现场安全地带，情况危急时拨打119、120、110请求支援。

**现场应急救援人员的职责：**

现场应急人员的主要职责是听从现场负责人的指挥，进行应急处置及现场急救等工作。

## 应急处置

### 可燃液体蒸气爆炸的处置

（1）发现火情，现场工作人员立即采取措施处理，防止火势蔓延并迅速报告。现场的操作人员应从源头上消灭化学品爆炸（如切断泄漏源、移走易燃物品等），正确使用消防器材（干粉灭火器、砂土等），按正确的灭火方法灭火，力争在化学品爆炸初期得到控制，力求最小的事故损失。

（2）人员应穿防护服、防毒面罩等措施加强自我保护，寻找附近消防栓，驳接好消防水带，扑救火灾爆炸，同时用消防水冷却和保护未爆炸燃烧区，隔离现场，切断电源、火源，防止事故扩大、蔓延。扑救时，若有作业人员困于火场之中，要优先救人，即“先救人，后救物”；用水压制火势，开辟出一条逃生通道。

若火灾爆炸快速蔓延，可能影响周边可燃物、建筑物时，应对可能被影响的可燃物、建筑物喷水进行冷却。

当消防救援队到来后，将事故情况向消防救援队说明清楚。应急队员服从消防救援队的指挥。如事故扩大有危及生命危险时，参与应急的队员应尽快撤离到安全地方。

（4）如当事故扩大危及到周围人员安全时，应迅速组织附近人员、友邻单位、过往行人协调下，向上侧风方向的安全地带疏散。

（5）当现场有人受伤或中毒时，应立即救护伤员和中毒人员，对中毒人员应根据中毒症状及时采取相应的急救措施，对伤员进行清洗包扎等急救处置，重伤员及时送往附近医院抢救。

### 疏散措施

1）现场负责人或其他人员确认发生危及员工人身安全的事故时，应立即向上报告，现场负责人在发现直接危及员工人身安全的紧急情况时，应立即组织人员疏散。

2）根据事故情况，周边100-500m 外设置警戒，设立相关警戒标志。

3）当有抢险救灾组或关部门（如消防队）到达事故现场后，现场负责人和工作人员主动汇报事故现场情况，指挥权上移后，积极协助做好疏散抢救工作。

### 报警（电话）及报警内容

1）电话：公司 24 小时值班电话 `{{COMPANY_24H_PHONE}}`；火灾报警 119；三警合一报警 110；急救中心 120。

2）应报告以下内容：报警单位名称、发生事故的时间、地点、事故的类型、发展和蔓延情况、现场处置和控制情况、引起火灾事故及人员伤亡等内容。

## 注意事项

（1）灭火人员在进行扑救时，应注意站在上风位置，保持必要的安全距离；

（2）在可能情况下迅速转移隔离化学品，防止火灾爆炸扩大；

（3）灭火人员应配戴好必要的个体防护用品，当火灾爆炸过大可能危及救护人员安全的，应迅速撤离现场。

（4）采取有效措施扑灭身上的火焰，使伤员迅速脱离开致伤现场。当衣服着火时，应采用各种方法尽快地灭火，如水浸、水淋、就地卧倒翻滚等，千万不可直立奔跑或站立呼喊，以免助长燃烧，引起或加重呼吸道烧伤。灭火后伤员应立即将衣服脱去，如衣服和皮肤粘在一起，可在救护人员的帮助下把未粘的部分剪去，并对创面进行包扎。

（5）防止休克、感染。为防止伤员休克和创面发生感染，应给伤员口服止痛片（有颅脑或重度呼吸道烧伤时，禁用吗啡）和磺胺类药，并饮淡盐茶水、淡盐水等。一般以多次饮少量为宜，如发生呕吐、腹胀等，应停止口服。要禁止伤员单纯喝白开水或糖水，以免引起脑水肿等并发症。

（6）保护创面。在火场，对于烧伤创面一般可不做特殊处理，尽量不要弄破水泡，不能涂龙胆紫一类有色的外用药，以免影响烧伤面深度的判断。为防止创面继续污染，避免加重感染和加深创面，对创面应立即用三角巾、大纱布块、清洁的衣服、被单等，给予简单而确实的包扎。手足被烧伤时应将各个指、趾分开包扎以防粘结。
