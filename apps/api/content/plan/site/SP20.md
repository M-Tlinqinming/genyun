# 可燃液体蒸气爆炸事故现场处置方案

## 事故风险描述

（1）事故类型：可燃液体蒸气爆炸是指 `{{REPRESENTATIVE_CHEMICALS}}` 等可燃液体（酒精、天那水、洗枪水、汽油、丙酮、甲苯、二甲苯、稀释剂、油漆等）在常温下从开口容器、泄漏处、敞开操作面持续挥发，挥发蒸气在受限或半受限空间内积聚至爆炸极限范围，遇明火、电火花、静电火花等点火源即发生爆炸（爆燃或爆轰）的事故。其物理本质是液体先挥发为蒸气、蒸气再与空气混合达到爆炸浓度——这一"两阶段"过程是与可燃气体爆炸（直接以气态泄漏）的根本差异：处置可燃液体蒸气爆炸必须从控制液源开始（围堵液体减少挥发面、收容回流），仅切断气源是无效的。本方案不覆盖可燃气体爆炸（按 SP19 处置）。

（2）事故区域：可燃液体储存场所（化学品库、油料库、调漆间、危险品仓）；调配、灌装、转移作业岗位（手工灌装台、灌装泵、调配釜、清洗槽）；喷涂、印刷、清洗等使用可燃液体溶剂的工序；可燃液体桶装存放区与堆场；曾经发生液体泄漏未彻底清理的车间地坪、地沟、围堰内。可燃液体挥发蒸气密度普遍大于空气，易在液面附近、地坪低洼处、地沟、围堰内、操作台下方持续积聚——这一积聚特征远比可燃气体扩散缓慢但持续时间更长。

（3）事故基本征兆及条件：现场闻到 `{{REPRESENTATIVE_CHEMICALS}}` 强烈刺鼻气味或溶剂特殊气味；可燃液体罐区或操作面可见液面外溢、桶体倾倒、阀门滴漏、管道接头渗漏、地坪积液；员工出现头晕、恶心、眼部刺激等溶剂中毒前兆；储罐液位计读数异常下降；通风系统停机或风量不足；员工违规在操作区使用非防爆电器、动火、穿化纤工服或铁钉鞋、未做静电接地直接进行液体倾倒；操作过程中出现可见火花（金属容器碰撞、铁工具击打、塑料容器拉裂等）。

（4）事故可能造成的危害程度：蒸气爆炸产生的冲击波和高温火球可造成人员烧伤、冲击伤甚至死亡；爆炸点周边可燃液体被引燃后形成液池火灾，沿地坪流淌火蔓延；储罐受热超压可触发二次爆炸（BLEVE 沸液膨胀蒸气爆炸）；溶剂蒸气在爆炸前未点燃阶段已可造成有机溶剂中毒；伴生火灾威胁邻近化学品库与生产装置。

## 应急工作职责

### 应急组织形式及人员

由现场班组长、化学品库管员或调漆/灌装岗位操作员、现场员工组成。无现场班组长的，由现场职务最高的员工或对事发区域负有安全责任的员工为现场负责人。

### 主要职责

**现场负责人职责：**

（1）无论在任何时候发生事故，现场负责人首先进入指挥岗位，做好应急处置工作，并安排将情况报告总指挥或副总指挥。

（2）评估事故的严重性及危害程度（液体类型、泄漏量、蒸气积聚范围、是否已点燃），现场应急力量是否有足够的能力进行处理，决定是否报告总指挥或副总指挥申请应急响应。

（3）下达上风方向疏散、围堵控制液源、消除点火源等关键指令；判断事故是否需要消防部门介入。

（4）如明确事故属于现场处置力量难以控制或人员难以救护性质的，则及早安排将重要物资、人员撤离现场到安全地带，及早拨打"120"请求救护。

**化学品库管员/灌装岗位操作员职责：**

（1）按 MSDS 与现场工艺，迅速判明泄漏点的最近一道阀门或封堵措施；倾倒桶应立即扶正、漏液阀门关闭、破损桶用应急漏液转桶接住或转移至安全围堰内。

（2）指导现场人员使用吸附材料（吸液棉、沙土、活性炭、专用吸附垫）覆盖液面或拦截流淌液——这是减少挥发面、控制蒸气源的关键动作。

（3）按厂区围堰、地沟堵漏措施，拦截流淌液回流至污水处理或专用收容池；严禁让可燃液体流入下水道或河道。

**现场应急救援人员职责：**听从现场负责人的指挥，进行应急处置及现场急救等工作。

## 应急处置

### 应急处置原则

救人第一的原则——若事故中有人员受到伤害或威胁，首要任务是救人，决不能因其他原因而耽误救人时机。处置可燃液体蒸气爆炸的核心是"控制液源（围堵收容、覆盖减蒸）→消除静电与点火源→机械排蒸→液体回收"——这一顺序是与可燃气体爆炸（远程切断气源、通风稀释气云）的根本差异：液体不会"自己消失"，必须主动收容；蒸气源头不在管道而在液面，仅通风无法治本。

### 应急处置程序

发生 `{{REPRESENTATIVE_CHEMICALS}}` 等可燃液体泄漏或蒸气爆炸事故，现场人员应立即将事故报告班（组）长，组长报应急总指挥和副总指挥。报警内容应包括：

（1）发生事故的时间；

（2）发生事故的具体位置（化学品库/调漆间/喷涂线/灌装台）；

（3）可燃液体类型、泄漏量、流淌覆盖面积；

（4）事故具体类型（仅泄漏未点燃 / 蒸气已爆燃 / 持续液池火 / 多次爆炸 / 储罐 BLEVE 风险）；

（5）受影响范围（围堰是否能完全收容、是否流入地沟）；

（6）人员受伤或失踪情况；

（7）次生灾害情况（伴生火灾、邻近化学品库受热、溶剂中毒等）。

### 现场应急处置措施

（1）人员撤离与防静电要求：现场人员从上风方向撤离至安全地点；撤离时严禁奔跑（人体与衣物摩擦产生静电）、严禁穿脱化纤外衣、严禁在事故区域使用塑料制品；进入事故区域处置的人员必须穿防静电服、防静电鞋，并先用接地把手释放静电后再操作。撤至安全地点后立即汇报班（组）长。

（2）控制液源（处置可燃液体蒸气爆炸的首要动作）——可燃液体的源头是液体本身而非气源，必须主动控制：
1）倾倒桶立即扶正；漏液阀门关闭；破损桶迅速转移至应急转桶或安全围堰内；
2）使用吸液棉、专用吸附垫、沙土覆盖流淌液面，减少与空气接触的挥发面；
3）按厂区围堰、地沟堵漏措施，将流淌液拦截在专用收容池或防火围堰内；
4）禁止用水冲洗可燃液体（水冲洗会扩大流淌面积、加速蒸气挥发，水油分离前不得排入下水道）。

（3）消除静电与点火源：可燃液体倾倒、流动、过滤过程中产生大量静电，处置中应——
1）所有金属容器、设备、管道、人员通过接地导线连接到等电位地网；
2）严禁穿化纤工服、铁钉鞋进入事故区域；
3）严禁使用非防爆电器、对讲机、手机、铁制工具（应使用铜制或防爆工具）；
4）严禁动火作业、吸烟，制止事故周边一切可能产生火花的活动；
5）已运行的非防爆电气设备一律保持当前状态，不得切换；空调、排风扇等如非防爆型应在远端切断电源。

（4）机械排蒸（针对积聚于低洼处的蒸气）：开启事故区域所有门窗自然通风；启动防爆型机械排风设备，重点抽吸液面附近、地坪、地沟、围堰内的低位蒸气——这一点与可燃气体爆炸的"通风稀释气云"在着力点上完全不同：可燃液体蒸气更重、积聚更集中，须低位强制排出而非高位扩散。

（5）已点燃情形的处置：液池火灾应使用泡沫灭火剂、干粉灭火剂或二氧化碳灭火剂扑救；禁止使用直流水柱（会扩大流淌面积），可用水雾隔离冷却邻近设备；储罐受热持续用水雾冷却外壁，防止 BLEVE 沸液膨胀蒸气爆炸；伴生火灾按 SP01 火灾事故处置方案联动。

（6）警戒与隔离：以泄漏点和液体覆盖区为中心，沿下风向延伸划定警戒区（一般 30m 以上，挥发性强或火灾风险高的液体延伸至 50m 以上）；警戒区内严禁机动车辆、动火作业、吸烟；液体回收完成、地坪蒸气浓度低于爆炸下限的 25% 之前，警戒不得解除。

### 医疗救护措施

（1）不要轻易移动受伤者，保持其呼吸道通畅；

（2）烧伤、冲击伤伤员按 SP06 灼烫事故、SP04 物体打击事故联动处置；化学品溅入眼内、皮肤接触按对应化学品 MSDS 实施冲洗（一般用大量清水冲洗 15 分钟以上）；

（3）有机溶剂中毒（头晕、恶心、意识模糊）的伤员立即转移至上风开阔处，必要时给氧；按 SP13 中毒事故处置方案联动；

（4）有出血时，应有效止血、包扎伤口；

（5）对失去知觉者，宜清除口鼻中的异物、分泌物、呕吐物，将伤员置于侧卧位以防窒息；

（6）如果伤者出现呼吸或心跳停止，应立即施行人工呼吸和胸外心脏按压，并速送医院。

## 注意事项

（1）严禁用水流直接冲刷可燃液体——水流会扩大液体覆盖面积、加速蒸气挥发并将可燃液体带入下水道，造成事故扩散；正确处置应是吸附、收容、转移。

（2）防静电是处置可燃液体蒸气爆炸的核心硬约束：禁穿化纤、禁用塑料、禁动铁器、严格接地——因液体倾倒和流动过程持续产生静电，仅消除明火不足以保证安全。

（3）严禁切换非防爆电气设备状态；事故附近的空调、排风扇、电脑、照明等如为非防爆型，断电应在远端总开关处实施。

（4）储罐受热风险：邻近事故区的可燃液体储罐持续用水雾冷却外壁，监测罐体温度与压力，发现安全阀起跳、罐壁鼓胀、异常嘶鸣等 BLEVE 前兆立即扩大警戒并请求消防强力支援。

（5）抢险人员必须佩戴好个人防护用品（防静电服、防静电鞋、防有机溶剂手套、正压式空气呼吸器、防爆工具）进入危险场所；如没有相应个人防护用品，不得盲目抢险和救护；伴生火灾按 SP01 联动，伴生中毒按 SP13 联动，化学品灼伤按 SP06 联动。

（6）参考所涉化学品 MSDS 选择对应处置措施；不同可燃液体的爆炸下限、闪点、毒性、相容性差异较大，灭火剂选择和防护装备选型必须以 MSDS 为准。
