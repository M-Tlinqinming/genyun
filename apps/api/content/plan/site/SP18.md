# 管道爆炸事故现场处置方案

## 事故风险描述

（1）事故类型：锅炉在运行中遇到特殊情况可能出现超压、缺水、爆管事故。如果处理不当会引起管道爆炸事故。

汽压急剧上升，超过锅炉许可工作压力，压力表指针超过“红线”，安全阀动作后，压力仍然在升高，发出超压警报信号，蒸汽温度升高而蒸汽流量减少。如果此时不迅速减弱燃烧，手动开启安全阀或放空阀，加大给水、加大排污，将会发生爆炸。

锅炉缺水时，水位表内水位低于极限水位而不可见，水位报警器发出低水位报警；锅炉排烟温度升高，缺水严重时，炉顶产生焦糊味，炉管变形甚至爆管，可听到爆破声，蒸汽和烟气从锅炉看火门喷出。如果此时向锅炉进水，将产生爆炸。

爆炸时锅炉的锅筒发生破裂，炉内一定压力的汽水混合物从破裂处迅速冲出，其能量立刻释放，瞬时降为大气压力而迅速膨胀汽化，产生巨大的作用和冲击波。

（2）事故风险区域：锅炉房。

**（3）事故基本征兆及条件：**

1）安全阀、压力表等安全装置失灵，操作人员脱岗，放弃对设备的监控，关闭或关小出气阀门造成锅炉“憋烧”；

2）锅炉主要受压元件出现裂纹、严重腐蚀、变型、组织变化等缺陷；

3）直接受火的筒体、封头、管板等严重缺水或突然加水。

4）锅炉给水泵失效或软水给水系统故障，不能向锅炉进水。

## 应急工作职责

### 应急组织形式及人员

由现场班组长和现场员工组成。无现场班组长的，由现场职务最高的员工或对事发区域负有安全责任的员工为现场负责人。

### 主要职责

**现场负责人职责：**

（1）无论在任何时候发生事故，现场负责人首先进入指挥岗位，做好应急处置工作，并安排将情况报告总指挥或副总指挥。

（2）评估事故的严重性及危害程度，现场应急力量是否有足够的能力进行处理，决定是否报告总指挥或副总指挥申请应急响应。

（3）如能有足够的人力物力处理事故，必须迅速调动相应的人力物力展开应急救援工作。

（4）如明确事故属于现场处置力量难以控制或人员难以救护性质的，则及早安排将重要物资、人员撤离现场安全地带。

**现场应急救援人员的职责：**

现场应急人员的主要职责是听从现场负责人的指挥，进行应急处置及现场急救等工作。

## 应急处置

1）应急处置原则：救人第一的原则，若事故中有人员受到伤害或威胁时，首要任务是救人，决不能因其它原因而耽误救人时机。

**2）应急处置程序**

事故报警：发生管道爆炸事故，现场人员应立即将事故报告班（组）长，组长报应急总指挥和副总指挥。

**报警内容应包括：**

发生事故的时间；

发生事故的具体部位；

事故具体类型；

事故范围、规模；

人员受伤或失踪情况；

次生灾害情况。

**现场应急处置措施：**

1）现场人员应迅速趴下，躲入墙体背后，以躲避冲击波，并防止热水、水蒸汽等烧伤。

2）沿疏散路线迅速逃离危险区，待撤到安全地点后立即汇报班（组）长。

3）现场人员应最大可能采取一切有效措施，阻止事故进一步扩大。

4）指挥部接到事故报告后，按汇报程序，通知相关人员到场。

5）有关人员到位后，要根据事故情况，制定相应的安全措施，进行事故抢险工作。

操作措施：一旦发生锅炉爆炸，运行人员应立即将事故情况报应急指挥部，防治扩大化事故。

1）发现锅炉严重缺水应紧急停炉，立即停止燃料供应，严禁向锅炉内进水。

2）发现炉管爆破后应紧急停炉。

3）炉膛爆炸、二次燃烧时应切断燃料供应，停止引风机，关闭烟道门。

4）燃料管道泄漏时应立即切断进料阀门，并采取相应的其他措施。

5）锅炉严重爆炸时要及时抢救有关人员，按照消防要求正确灭火，防治周边易燃、易爆物二次爆炸燃烧。

**人员救护：**

1）将受伤人员转移到安全区域。

2）询问伤者并观察受伤的部位，判断具体伤害类型。对心跳呼吸骤停者，立即施行人工呼吸和胸外心脏按压，保持呼吸道通畅，松开阻碍呼吸的衣物。

3）对失去知觉者宜清除口鼻中的异物、分泌物、呕吐物，随后将伤员置于侧卧位以防窒息。

4）如有外伤，对伤者进行止血。视情况不同选取采用包扎法、加压包扎法、指压法止血。

5）固定（创伤部位的制动）：可减轻疼痛刺激、防治再出血和损伤。肢体制动可用夹板，躯干制动可借助于担架和束带。应注意搬动伤员时勿使伤处移位、扭曲、震动。

6）对严重创伤伤员（大出血、多发性创伤、断肢等），等待专业人员救护。

## 注意事项

（1）在发生事故后应根据现场情况，在保证自身安全的前提下，采取积极有效的方法进行救援。

（2）现场救援人员在开展工作时首先要确保个人安全，穿戴防护服、防护鞋。

（3）抢救伤员时，要询问伤员伤情，伤情严重时，非医务人员不得搬动伤员。
