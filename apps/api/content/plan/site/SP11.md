# 高处坠落事故现场处置方案

## 事故风险描述

（1）操作人员在设备高处检修或厂房高处等登高作业过程中（离基准面2米以上），作业平台无防护栏杆、防护栏杆失效或作业人员没有使用相应的防护设备，会发生高处坠落事故。

（2）事故发生区域：各从事高处作业的场所。

（3）事故基本征兆及条件：人员在2m或2m以上的作业平台作业，机械设备上检修、维护、作业时，高处从事设备、设施的安装、维护、保养时，若没有按要求使用安全防护用品或防护用品存在质量缺陷、安全带固定点不牢，错误使用等，可能发生高处坠落导致人员伤亡。

（4）事故可能造成的危害程度：可能造成人员摔伤、骨折，严重的造成死亡。

## 应急工作职责

### 应急组织形式及人员

由现场班组长和现场员工组成。无现场班组长的，由现场职务最高的员工或对事发区域负有安全责任的员工为现场负责人。

### 主要职责

**现场负责人职责：**

（1）无论在任何时候发生事故，现场负责人首先进入指挥岗位，做好应急处置工作，并安排将情况报告总指挥或副总指挥。

（2）估算事故的严重性及危害程度，现场应急力量是否有足够的能力进行处理，决定是否报告总指挥或副总指挥申请应急响应。

（3）如能有足够的人力物力处理事故，必须迅速调动相应的人力物力展开应急救援工作。

（4）如明确事故属于现场处置力量难以控制或人员难以救护性质的，则及早安排将重要物资、人员撤离现场到安全地带。

**现场应急救援人员的职责：**

现场应急人员的主要职责是听从现场负责人的指挥，进行应急处置及现场急救等工作。

## 应急处置

**1）事故应急处置**

（1）用担架等工具，保持伤者全身不能异动，并迅速将伤员脱离危险地带，移至安全地带。

（2）有效止血，包扎伤口。

（3）保持呼吸道通畅，若发现窒息者，应及时解除其呼吸道梗塞和呼吸机能障碍，应立即解开伤员衣领，消除伤员口鼻、咽、喉部的异物、血块、分泌物、呕吐物等。

（4）如脊柱受损，为防止受损脊柱压迫中枢神经，应进行有效固定后送医院处理或拨打“120”急救电话等待救援。

（5）伤员有骨折，关节伤、肢体挤压伤，大块软组织伤都要固定。

（6）视其伤情采取报警或直接送往医院，或待简单处理后去医院检查。

（7）若伤员有断肢情况，应尽早用干净的干布（灭菌敷料）包裹装入塑料袋内，随伤员一起转送。

**2）报警（电话）及报警内容：**

（1）电话：公司 24 小时值班电话 `{{COMPANY_24H_PHONE}}`；三警合一报警 110；急救中心 120。

（2）应报告以下内容：报警单位名称、发生事故的时间、地点、事故的类型、发展和蔓延情况、现场处置和控制情况、引起伤害及人员伤亡等内容。

## 注意事项

（1）使用抢险救援器材的设备应完好。

（2）在发生事故后应根据现场情况，在保证自身安全的前提下，采取积极有效的方法进行救援。

（3）不得随意挪动伤员的肢体。
