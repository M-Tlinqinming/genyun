# 高温熔融物爆炸事故现场处置方案

## 事故风险描述

**（1）事故特征：**

生产过程中涉及高温熔融金属（如钢水、铁水、铝液）或熔渣的作业过程中，若熔融物与潮湿物料、积水、带水工具或设备接触，会因水分瞬间剧烈汽化（蒸汽爆炸）而导致熔融物发生喷溅、爆炸。事故可造成严重的喷射性烧伤、火灾、设备损毁、建构筑物坍塌，并可能引发二次事故（如电气短路火灾、可燃气体爆炸等）。

**（3）事故前可能出现的征兆及条件：**

如设备与场地条件：炉坑、浇注坑、地面积水未及时清理；设备（如钢包、中间包、流槽）烘烤不干，内壁潮湿；冷却水管、蒸汽管道泄漏。

物料条件：加入炉内的废钢、合金等原料潮湿、含密封容器或冰雪。

作业过程：违规向熔融物中投掷潮湿物料；在潮湿地面进行浇注作业；用带有水渍的工具进行取样、扒渣等操作。

环境条件：雨天，厂房漏雨，导致熔融物作业区域或物料被淋湿。

## 应急工作职责

### 应急组织形式及人员

由现场班组长和现场员工组成。无现场班组长的，由现场职务最高的员工或对事发区域负有安全责任的员工为现场负责人。

### 主要职责

**现场负责人职责：**

（1）无论在任何时候发生事故，现场负责人首先进入指挥岗位，做好应急处置工作，并将情况报告总指挥或副总指挥。

（2）估算事故的严重性及危害程度，现场应急力量是否有足够的能力进行处理，决定是否报告总指挥或副总指挥申请外部救援力量支援。

（3）如能有足够的人力物力处理事故，必须迅速调动相应的人力物力展开应急救援工作。

（4）如明确事故属于现场处置力量难以控制或人员难以救护性质的，则及早安排将重要物资、人员撤离现场安全地带，情况危急时`{{FIRE_DEPT_NAME}}`“`{{FIRE_DEPT_PHONE}}`”、120、110请求支援。

**现场应急救援人员的职责：**

现场应急人员的主要职责是听从现场负责人的指挥，进行应急处置及现场急救等工作。

## 应急处置

1）第一发现人应立即高声呼警，并迅速通过{{COMMS}}等方式通知周边所有人员紧急撤离。

2）立即停止相关作业，在确保自身安全的前提下，远程切断事故区域电源、气源。

3）现场负责人立即组织清点人员，确认有无人员被困或受伤，并设立警戒区，严禁无关人员进入。

**4）对烧伤伤员进行急救：**

迅速脱离热源：用大量流动冷水持续冲洗或浸泡伤处15-30分钟，切勿强行剥除粘附的衣物。

保护创面：用清洁的布料、纱布覆盖伤口，避免污染。

保持呼吸道通畅：特别注意面部、颈部烧伤或有吸入性损伤风险的伤员。

保暖、平卧：去除伤者身上的手表、戒指等物品，用干净布料覆盖身体保暖，让伤者平卧，减少搬动。

在确保无二次爆炸风险（如积水已清除、泄漏已控制）后，组织有防护的应急人员使用干砂、专用灭火剂扑灭由熔融物引燃的初期火灾，严禁使用水或泡沫直接扑救熔融物火灾。

配合外部救援力量，引导其进入现场，并告知事故物质、伤亡、被困人员等关键信息。

**报警电话及内容：**

（1）电话：公司 24 小时值班电话 `{{COMPANY_24H_PHONE}}`；火灾报警 119；三警合一报警 110；急救中心 120。

（2）应报告以下内容：报警单位名称、发生事故的时间、地点、事故的类型、发展和蔓延情况、现场处置和控制情况、引起伤害及人员伤亡等内容。

## 注意事项

1）应急抢险人员必须佩戴齐全耐高温防护服、面罩、防砸防刺穿劳保鞋、隔热手套等个人防护装备，方可进入危险区域。

2）坚持“救人第一”原则，在保证救援人员安全的前提下，优先抢救伤员。

3）处置时必须先确认现场无积水、设备无泄漏，彻底消除水源，防止发生二次爆炸。

4）现场应储备足量的干燥黄砂、熔融金属专用灭火毯或灭火剂。

5）事故处置完毕后，需经专业人员确认现场高温熔融物已完全固化、无复燃及二次爆炸风险后，方可解除警戒。
