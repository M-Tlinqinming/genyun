# 道路（轨道）车辆致害事故现场处置方案

## 事故风险描述

（1）事故类型：公司自备车队、货物运输业务车辆、长途运输车辆、班车、外协运输车辆等在城市道路、高速公路、国道/省道/县道等公共道路上发生的交通事故；以及厂内涉及铁路、有轨/无轨等轨道交通运输车辆发生的撞击、碾压、出轨、倾覆事故。本方案聚焦公共道路 + 轨道场景；厂区内场地的非道路车辆事故按 SP07 厂内车辆致害事故现场处置方案处置，本方案不重复覆盖厂区内场景。

（2）事故区域：公司自备车队/货运车辆行驶的城市道路、高速公路、国道/省道/县道；厂内铁路装卸作业线、轨道运输专用线、与公共铁路接轨的厂线；以及上述道路/轨道延伸的桥梁、隧道、涵洞。

（3）事故基本征兆及条件：车辆制动性能下降、轮胎磨损、转向系故障、灯光信号失效；驾驶员疲劳驾驶、酒驾/药驾、超速、违章变道；恶劣天气（雨、雪、雾、冰、强风）；超载、装载偏置、捆扎不牢致货物坠落；轨道信号失误、瞭望疏忽、限速违章、轨距/道岔故障、设备人员闯入。

（4）事故可能造成的危害程度：人员伤亡（驾驶员、随车人员、行人、对方车辆乘员），车辆损毁、货物损失，可能引发二次事故（追尾、碾压、火灾、泄漏）；轨道事故可能阻断运输线路、波及电气化接触网。

## 应急工作职责

### 应急组织形式及人员

由现场负责人、车队管理员、驾驶员和现场应急救援人员组成。事故发生时由车上职务最高的员工或对车辆负有安全责任的员工为现场负责人。

### 主要职责

**现场负责人（车队管理员/带队司机长）职责：**

（1）无论在任何时候发生事故，现场负责人首先进入指挥岗位，做好应急处置工作，并安排将情况报告总指挥或副总指挥。

（2）评估事故严重性、是否涉及伤亡、是否伴生危化品泄漏或火灾，决定是否启动综合应急预案、是否申请外部专业救援。

（3）公路事故立即拨打 122/110；轨道事故立即通知厂内调度中心或铁路调度，必要时联系电气段断电；伴生火灾或危化品泄漏时同步拨打 119。

（4）如能有足够的人力物力处理事故，必须迅速调动相应的人力物力展开应急救援工作；必要时协调拖车、备用车辆和外部资源。

**驾驶员职责：**

（1）立即停车保护现场，开启危险报警闪光灯。

（2）公路事故：在车后规定距离外（高速 ≥ 150m / 普通公路 50–100m / 雨雾雪天加倍）放置三角警示牌；车上人员撤至护栏外或路肩之外避免二次事故。

（3）轨道事故：在事故区段前后按规定距离设置阻拦信号（红旗、信号灯、响墩），迅速拦停后续机车。

（4）救助伤员、保护现场不被破坏，配合警察/调度员调查；保留行车记录仪、运单、随车文件作为证据。

**车队管理员职责：** 接到事故报告后立即向公司报告，赶赴现场组织救援；协调拖车、备用车辆和外部资源；协助警方/铁路调度部门调查取证。

**现场应急救援人员职责：** 听从现场负责人的指挥，进行应急处置及现场急救等工作。

## 应急处置

### 报警与警示标志

（1）公路事故：立即拨打 122 道路交通事故报警/110 三警合一报警；轨道事故立即通知厂内调度中心或铁路调度断电封锁线路；伴生危化品泄漏或火灾时同步拨打 119。

（2）公路事故现场设三角警示牌：高速公路 ≥ 150m 处；普通公路 50–100m 处；雨雾雪、夜间加倍距离；车上人员撤至护栏外或路肩之外避免二次事故。

（3）厂内轨道事故：按厂内铁路作业指导书在事故区段前后设防护标志（红旗/信号灯/响墩），迅速拦停后续机车，必要时线路两端同时防护。

### 伤员救护

（1）不要轻易移动受伤者，保持其呼吸道通畅。

（2）有出血时，应有效止血，包扎伤口。

（3）如果发生骨折，用双手稳定及承托受伤部位，限制骨折处活动并设置软垫，用绷带、夹板或替代品妥善固定伤肢。

（4）发生断指（肢）应立即止血，尽可能将断指（肢）冲洗干净，用消毒敷料袋包好，放入装有冷饮的塑料袋外侧，将断指（肢）与伤者立即送往医院。

（5）如果伤者出现呼吸或心跳停止，应立即进行心肺复苏急救（人工呼吸 + 胸外按压）。

（6）伤员被压车下时：用千斤顶、撬棍等将挤压部位扩张救出；如发现漏油或危险化学品泄漏场景，疏散无关人员，禁止点火源出现。

### 现场保护

（1）在确保人员安全前提下，保留事故现场不被破坏；如必须移动伤员或挪动车辆才能救护，应在地面用粉笔/喷漆等标记车辆和散落物的原始位置。

（2）妥善保管行车记录仪、车载视频、运单等证据材料；不得擅自离开事故现场。

（3）配合交警、铁路调度、消防、应急管理等外部部门的调查取证。

### 报警电话及报警内容

（1）电话：公司 24 小时值班电话 `{{COMPANY_24H_PHONE}}`；三警合一报警 110；道路交通事故报警 122；急救中心 120；厂内轨道事故同步通知厂内调度/铁路调度断电封锁；如伴生危化品泄漏或火灾还应拨打 119。

（2）应报告以下内容：报警单位名称、发生事故的时间、地点（公路里程桩号 / 轨道线别和公里标）、事故的类型（追尾/碰撞/碾压/出轨/翻车）、事故发展和蔓延情况、车辆型号牌号、人员伤亡、有无危化品泄漏/火灾次生事故、现场处置和控制情况等内容。

## 注意事项

（1）高速公路事故警示距离 ≥ 150m，普通公路 50–100m，雨雾雪、夜间须加倍；车上人员撤离至护栏外或路肩之外，不得在车道、应急车道附近滞留，防二次事故。

（2）厂内轨道事故必须先确认接触网/动力线已断电、线路已封锁后才能进入轨道及车辆下方救人；严禁在未断电情况下登顶车辆或接触接触网/受电弓附近金属构件。

（3）涉及伤亡的公路事故，必须按 122/110 要求等待交警到场，不得擅自移车；移车前应做现场标记并保留照片证据。

（4）漏油或可燃液体泄漏现场严禁明火、电器开关操作、手机非必要使用，疏散下风向人员；漏出危化品按 SP09 泄漏事故联动处置。

（5）救援与处理过程中保持与公司应急办、车队、调度、保险公司的有效通讯，统一对外口径，避免信息混乱。

（6）事故后驾驶员应配合酒精检测、毒品检测、行车记录调取等调查程序，不得离开事故现场。
