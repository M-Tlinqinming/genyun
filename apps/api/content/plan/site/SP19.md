# 可燃气体爆炸事故现场处置方案

## 事故风险描述

（1）事故类型：可燃气体爆炸是指 `{{COMBUSTIBLE_GAS}}`（如液化石油气、天然气、氢气、乙炔、甲烷、一氧化碳等可燃气体）从储存容器、输送管道、用气设备处泄漏后，在敞开或半封闭空间扩散，与空气混合至爆炸极限范围内，遇明火、电火花、静电、高温表面等点火源即发生预混气云爆炸（爆燃）的事故。其物理本质是气态可燃物在大气压下的快速燃烧反应，不同于容器爆炸（容器内压力释放）和管道爆炸（管道介质轴向喷出）。本方案不覆盖可燃液体挥发蒸气引发的爆炸（按 SP20 处置）。

（2）事故区域：`{{COMBUSTIBLE_GAS}}` 储罐区（液化气罐、气瓶柜、储气罐）；调压间、用气设备（燃气炉具、热处理炉、焊接气割站）周边；可燃气体管道沿线及阀门站；曾经发生气体泄漏未充分通风的车间、地沟、地下室、密闭操作间。气体密度大于空气者（如液化石油气）易在低洼处积聚，密度小于空气者（如氢气、天然气）易在屋顶、夹层处积聚。

（3）事故基本征兆及条件：可燃气体报警仪报警；现场闻到 `{{COMBUSTIBLE_GAS}}` 特有气味（如天然气加臭剂硫醇味、液化气特殊气味）；储罐压力表读数异常下降；管道法兰、阀门处嘶鸣漏气声或可见结霜（液化气类）、雪花结霜（极低温介质）；气瓶或管道周围植物枯黄、保温层湿斑；员工出现头晕、恶心等中毒前兆（部分可燃气体如一氧化碳兼具毒性）；气源切断阀失效、防爆电气器件外壳破损或非防爆电器违规进入用气区域。

（4）事故可能造成的危害程度：爆燃产生的冲击波和高温火球可造成人员烧伤、冲击伤甚至死亡；爆炸中心可摧毁邻近设备、厂房；伴生火灾沿可燃物蔓延；带有毒性的可燃气体（一氧化碳、氨气）爆炸前未点燃阶段已可造成大范围中毒；爆炸冲击可触发邻近气瓶、压力容器二次爆炸。

## 应急工作职责

### 应急组织形式及人员

由现场班组长、用气岗位操作员和现场员工组成。无现场班组长的，由现场职务最高的员工或对事发区域负有安全责任的员工为现场负责人。

### 主要职责

**现场负责人职责：**

（1）无论在任何时候发生事故，现场负责人首先进入指挥岗位，做好应急处置工作，并安排将情况报告总指挥或副总指挥。

（2）评估事故的严重性及危害程度（泄漏量、扩散范围、是否已点燃），现场应急力量是否有足够的能力进行处理，决定是否报告总指挥或副总指挥申请应急响应。

（3）下达上风方向疏散、远程切断气源、消除点火源等关键指令；判断事故是否需要消防部门介入。

（4）如明确事故属于现场处置力量难以控制或人员难以救护性质的，则及早安排将重要物资、人员撤离现场到安全地带，及早拨打"120"请求救护。

**用气岗位操作员职责：**

（1）熟悉本岗位 `{{COMBUSTIBLE_GAS}}` 工艺流程图，迅速判明可在防爆区域外或上风处操作的最近一道气源切断阀，按操作规程切断气源；现场不具备远程切断条件时联系上一级供气单位（如燃气公司、动力站）实施切断。

（2）按操作规程关闭事故区域气体输送泵、压缩机；启动事故现场固定式机械通风系统（必须为防爆型）。

（3）严格遵守"严禁在爆炸性气体环境中操作非防爆电器"的硬约束，事故区域内一切电气操作（合闸、断闸、插拔）须在防爆区域外的总开关处实施。

**现场应急救援人员职责：**听从现场负责人的指挥，进行应急处置及现场急救等工作。

## 应急处置

### 应急处置原则

救人第一的原则——若事故中有人员受到伤害或威胁，首要任务是救人，决不能因其他原因而耽误救人时机。处置可燃气体爆炸的核心是"先消除点火源、再切断气源、后通风稀释"——这一顺序是与可燃液体蒸气爆炸（先围堰收容控制源头、再排蒸）的根本差异。

### 应急处置程序

发生 `{{COMBUSTIBLE_GAS}}` 泄漏或爆炸事故，现场人员应立即将事故报告班（组）长，组长报应急总指挥和副总指挥。报警内容应包括：

（1）发生事故的时间；

（2）发生事故的具体位置（罐区/管道阀门站/用气车间）；

（3）`{{COMBUSTIBLE_GAS}}` 类型及泄漏量评估；

（4）事故具体类型（仅泄漏未点燃 / 已发生爆燃 / 持续燃烧 / 多次爆炸）；

（5）扩散方向（风向、地形）及波及范围；

（6）人员受伤或失踪情况；

（7）次生灾害情况（伴生火灾、邻近气瓶受热、有毒成分扩散等）。

### 现场应急处置措施

（1）人员上风疏散：现场人员立即从上风方向、垂直于扩散主方向撤离至安全地点；密度大于空气的 `{{COMBUSTIBLE_GAS}}`（如液化石油气）撤离时禁止经过低洼处、地沟、地下室；密度小于空气的 `{{COMBUSTIBLE_GAS}}`（如氢气、天然气）应避开建筑屋顶、夹层等积聚区。撤至安全地点后立即汇报班（组）长。

（2）严禁明火与点火源（处置可燃气体爆炸的首要硬约束）：立即制止事故区域及邻近区域一切动火作业、吸烟、使用打火机；禁止使用非防爆手机、对讲机、手电、相机；禁止穿化纤衣物、铁钉鞋进入事故区域；禁止启动或停止非防爆电气设备（操作电气开关本身即可产生火花引爆气云）；现场已使用的非防爆电器一律保持当前状态，不得切换。

（3）远程切断气源（在防爆区域外或上风处操作）：用气岗位操作员或维护工按工艺流程图，迅速关闭事故点上游的最近气源切断阀；优先使用紧急切断阀（ESD）、远程电动阀；如最近阀门位于爆炸危险区域内，由穿戴防静电服、使用铜质防爆扳手的人员配合在规定时间内完成切断操作，操作前必须确认无明火、无静电积累。

（4）通风稀释（降低气云浓度至爆炸下限以下）：开启事故区域所有门窗实施自然通风；启动防爆型机械通风设备（轴流风机、防爆排风机），将气云向开放空间扩散；可燃气体浓度未确认低于爆炸下限的 25% 之前，严禁人员进入事故核心区。

（5）已点燃情形的处置：稳定燃烧（即气源持续供应下的稳态火焰）一般不强行扑灭——应保持稳定燃烧并冷却周边设备，防止气源切断不彻底导致再次形成爆炸性混合物；待气源切断后火焰自然熄灭。火焰已蔓延至邻近可燃物时按 SP01 火灾事故处置方案联动。

（6）警戒与隔离：以泄漏点为中心，结合风向沿下风向延伸划定警戒区（液化气类延伸 30m 以上，氢气/乙炔等高反应性气体延伸 50m 以上）；警戒区内禁止机动车辆进入（车辆点火、排气均为点火源）；事故附近气瓶、储罐用水雾持续冷却，防止受热超压。

### 医疗救护措施

（1）不要轻易移动受伤者，保持其呼吸道通畅；

（2）烧伤、冲击伤伤员按 SP06 灼烫事故、SP04 物体打击事故联动处置；烧伤伤员脱离热源后用洁净敷料覆盖伤面，避免揭除粘连衣物；

（3）伴生中毒（一氧化碳、硫化氢等）的伤员立即转移至上风开阔处，必要时给氧；

（4）有出血时，应有效止血、包扎伤口；

（5）对失去知觉者，宜清除口鼻中的异物、分泌物、呕吐物，将伤员置于侧卧位以防窒息；

（6）如果伤者出现呼吸或心跳停止，应立即施行人工呼吸和胸外心脏按压，并速送医院。

## 注意事项

（1）严禁使用非防爆电器、对讲机、手机进入事故区域；事故区域内已运行的电气设备不得切换状态——切换电气开关本身即可产生足以引爆气云的电火花。

（2）切断气源是处置可燃气体爆炸的根本手段；通风稀释和扑救火焰是辅助手段，气源未切断前现场风险持续存在。

（3）严禁强行扑灭由稳定气源供应支撑的稳态火焰——熄灭后未燃尽的可燃气体将继续扩散并形成更大范围的爆炸性混合物，造成"二次爆炸"风险。

（4）防回火爆炸：切断气源时关闭速度不宜过快（高压气源急关易在管道内产生回火），按操作规程逐级降压；事故区域所有阀门操作严格按持证人员操作规程实施。

（5）抢险人员必须佩戴好个人防护用品（防静电服、防静电鞋、正压式空气呼吸器、防爆工具）进入危险场所；如没有相应个人防护用品，不得盲目抢险和救护；伴生火灾按 SP01 联动，伴生有毒中毒按 SP13 联动。

（6）警戒区按下风向纵深布置，气体密度大于空气者重点警戒低洼区，气体密度小于空气者重点警戒制高点；浓度未确认安全前严禁解除警戒。
