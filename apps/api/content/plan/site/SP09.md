# 泄漏事故现场处置方案

## 事故风险描述

（1）事故类型：车间化学品临时存放点、化学品暂存仓储存的危险化学品因包装桶密封盖损坏、包装桶破裂导致化学液体泄漏；液体化学品在搬运、运输过程中受撞击等破损泄漏。当存在泄漏源，遇明火或火花即可产生燃烧爆炸，人员吸入或误服可致中毒窒息事故。

（2）事故风险区域：车间化学品临时存放区、化学品暂存间、调油房等。

（3）事故基本征兆及条件：包装桶密封盖损坏、包装桶破裂、液体化学品在搬运、运输过程中受撞击等破损泄漏。

## 应急工作职责

### 应急组织形式及人员

由现场班组长和现场员工组成。无现场班组长的，由现场职务最高的员工或对事发区域负有安全责任的员工为现场负责人。

### 主要职责

**现场负责人职责：**

（1）无论在任何时候发生事故，现场负责人首先进入指挥岗位，做好应急处置工作，并安排将情况报告总指挥或副总指挥。

（2）评估事故的严重性及危害程度，现场应急力量是否有足够的能力进行处理，决定是否报告总指挥或副总指挥申请应急响应。

（3）如能有足够的人力物力处理事故，必须迅速调动相应的人力物力展开应急救援工作。

（4）如明确事故属于现场处置力量难以控制或人员难以救护性质的，

则及早安排将重要物资、人员撤离现场安全地带。

**现场应急救援人员的职责：**

现场应急人员的主要职责是听从现场负责人的指挥，进行应急处置及现场急救等工作。

## 应急处置

**1）事故应急处置**

（1）立即疏散周围无关人员到安全区域；

（2）查找泄漏源，实施现场堵漏处理及物料转移处理；

（3）包装桶泄漏：立即停用该包装桶的物料，换包装或采用接料桶转移物料；

（4）不能实现转移包装容器内的易燃、有毒物质情形的，则将泄漏的包装桶转移至厂区空旷地，进行泄漏物收集处理；

（5）溶剂泄漏物收集处理：使用盘、桶盛接，防止液体流散。可采用导流法把流散液体积聚在某一低洼处，或人工挖的坑池中，然后安全回收。

泄漏地点地面以沙土覆盖已泄漏的易燃液体液面，减少挥发，隔绝空气溢出的溶剂蒸气，减少挥发，隔绝空气。

（6）驱散蒸气：易燃液体蒸气大都比空气重，一般都沉聚于地表或低洼处，不易飘散。室外可使用雾壮水流驱散液体蒸气，尤其要对液体蒸气积聚处要认真驱散，室内则应打开门窗通风，必要时也可采用雾状水驱散，

对地下沟、槽等处也应采取措施驱散蒸气，以彻底消除险情。

**2）报警（电话）及报警内容：**

（1）电话：公司 24 小时值班电话 `{{COMPANY_24H_PHONE}}`；火灾报警 119；三警合一报警 110；急救中心 120。

（2）应报告以下内容：报警单位名称、发生事故的时间、地点、事故的类型、发展和蔓延情况、现场处置和控制情况、引起的车辆伤害及人员伤亡等内容。

## 注意事项

（1）应急人员应配戴必要的个人防护用具，如防毒面罩、防护服等。

（2）泄漏物为易燃易爆物质，应急现场严禁火种及使用易产生火花的工具。

（3）作业过程不宜单独行动，应统一指挥、协调监护。

（4）清理溢料地面时严禁使用铁、钢制工具、塑料以及化纤器具，以免发生碰撞摩擦起火，并应把吸有物料的沙土等物品放入桶中加盖，贴上标记。严禁任何点火源（包括明火、火花）带入警戒区，并根据风向的变化调整警戒区的大小，在下风向保留较大范围的区域。
