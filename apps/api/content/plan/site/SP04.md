# 物体打击事故现场处置方案

## 事故风险描述

（1）生产过程中在搬运、堆装各原材料、产品等过程中，若操作人员违反操作规程、粗心大意、相互配合不当，或其它意外因素引起物体坠落、倾倒，都能引起砸伤、压伤人员的物体打击事故，各车间、仓库均存在发生物体打击的可能。

（2）事故区域：生产车间、仓库、作业平台等。

（3）事故基本征兆及条件：因工作平面无踢脚板、物品工具等随意摆放等坠落物将人击伤。

（4）事故可能造成的危害程度：如人员被物体击中，可能造成伤残、死亡，以及引发其他安全生产事故。

## 应急工作职责

### 应急组织形式及人员

由现场班组长和现场员工组成。无现场班组长的，由现场职务最高的员工或对事发区域负有安全责任的员工为现场负责人。

### 主要职责

**现场负责人职责：**

（1）在任何时候发生事故，现场负责人首先进入指挥岗位，做好应急处置工作，并安排将情况报告总指挥或副总指挥。

（2）估算事故的严重性及危害程度，现场应急力量是否有足够的能力进行处理，决定是否报告总指挥或副总指挥申请应急响应。

（3）如能有足够的人力物力处理事故，必须迅速调动相应的人力物力展开应急救援工作。

（4）如明确事故属于现场处置力量难以控制或人员难以救护性质的，则及早拨打“120”请求救护。

现场应急救援人员的职责：现场应急人员的主要职责是听从现场负责人的指挥，进行应急处置及现场急救等工作。

## 应急处置

**1）事故应急处置**

（1）在伤情允许情况下，采取防护措施后将受伤人员救离现场，转移到安全地方；

（2）应迅速对周围环境进行确认，仍存在危险因素下，立即组织人员防护，并禁止人员进出。

（3）受伤人员的急救

当发生物体打击事故后，抢救的重点放在颅脑损伤、胸部骨折和出血上进行处理。

①发生物体打击事故后，应马上组织抢救伤者，首先观察伤者的受伤情况、部位、伤害性质，如伤员发生休克，应先处理休克。遇呼吸、心跳停止者，应立即进行人工呼吸，胸外心脏挤压。处于休克状态的伤员要让其安静、保暖、平卧、少动，并将下肢抬高约20度左右，尽快送医院进行抢救治疗。如果是脊柱骨折，不要弯曲、扭动患者的颈部和身体，不要接触患者的伤口，要使患者身体放松，尽量将患者放到担架或平板上进行搬运。

②出现颅脑损伤，必须维持呼吸道通畅。昏迷者应平卧，面部转向一侧，以防舌根下坠或分泌物、呕吐物吸入，发生喉阻塞。有骨折者，应初步固定后再搬运。遇有凹陷骨折、严重的颅底骨折及严重的脑损伤症状出现，创伤处用消毒的纱布或清洁布等覆盖伤口，用绷带或布条包扎后，及时送就近有条件的医院治疗。

**2）报警（电话）及报警内容：**

（1）电话：公司 24 小时值班电话 `{{COMPANY_24H_PHONE}}`；火灾报警 119；三警合一报警 110；急救中心 120。

（2）应报告以下内容：报警单位名称、发生事故的时间、地点、事故的类型、发展和蔓延情况、现场处置和控制情况、引起的物体打击及人员伤亡等内容。

## 注意事项

（1）在发生事故后应根据现场情况，在保证自身安全的前提下，采取积极有效的方法进行救援。

（2）救援时不得随意搬动受伤人员，必须采取防止二次伤害的安全措施。
