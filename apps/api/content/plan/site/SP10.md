# 粉尘爆炸事故现场处置方案

## 事故风险描述

**（1）事故特征：**

开料生产过程中，对木材等进行开料、打磨等过程中会产生大量粉尘（可燃粉尘），当粉尘浓度达到爆炸极限，在火源或者强烈振动与摩下可能引起粉尘爆炸，通风除尘系统为除尘集尘设备，在密封空间的粉尘达到一定浓度，遇火星、高热等易导致粉尘爆炸，造成火灾、人员伤残、死亡，以及引发其他安全生产事故。

（2）事故可能发生的区域：木工车间、除尘系统。

**（3）事故前可能出现的征兆及条件：**

如果车间粉尘清扫不及时、通风系统不畅、当粉尘浓度超过爆炸极限，遇到违规焊割、打磨明火、静电火花、烟头等即可能发生粉尘爆炸事故。

**事故可能造成的危害程度：**

粉尘爆炸可能造成火灾爆炸、窒息、人员伤残、死亡，以及引发其他安全生产事故。

## 应急工作职责

### 应急组织形式及人员

由现场班组长和现场员工组成。无现场班组长的，由现场职务最高的员工或对事发区域负有安全责任的员工为现场负责人。

### 主要职责

**现场负责人职责：**

（1）无论在任何时候发生事故，现场负责人首先进入指挥岗位，做好应急处置工作，并将情况报告总指挥或副总指挥。

（2）估算事故的严重性及危害程度，现场应急力量是否有足够的能力进行处理，决定是否报告总指挥或副总指挥申请外部救援力量支援。

（3）如能有足够的人力物力处理事故，必须迅速调动相应的人力物力展开应急救援工作。

（4）如明确事故属于现场处置力量难以控制或人员难以救护性质的，则及早安排将重要物资、人员撤离现场安全地带，情况危急时`{{FIRE_DEPT_NAME}}`“`{{FIRE_DEPT_PHONE}}`”、120、110请求支援。

**现场应急救援人员的职责：**

现场应急人员的主要职责是听从现场负责人的指挥，进行应急处置及现场急救等工作。

## 应急处置

1）现场作业人员发生粉尘爆炸事故后，立即停机、断电、通风最大限度降低粉尘浓度。

2）通知现场及附近人员紧急撤离事故现场，并立即向现场负责人或上级报告。.

3）当事故超出企业自救能力时，及时拨打110报警电话和120急救电话。

4）撤离爆炸现场附近的可燃物，避免爆炸引起火灾区域扩大。

5）迅速将伤者移到安全地方，让伤者安静、保暖、平卧、少动。并将下肢抬高约20度左右。

6）使昏迷者平卧，面部转向一侧，以防舌根下坠或分泌物、呕吐物吸入，发生咽喉阻塞。

7）发现伤者手足骨折或其他部位骨折的，不要盲目搬动伤者，应在骨折部位用夹板临时固定，使断端不再移位或刺伤肌肉、神经或血管；固定办法。以固定骨折处上下关节为原则，可以就地取材，用木板、竹片等，在无材料的情况下，上肢可固定在身侧，下肢与腱侧下肢缚在一起

8）遇有创伤性出血的伤员，应迅速包扎止血，使伤员保持在头低脚高的卧位，并注意保暖；

9）在施救的同时应尽快送往就近医院；伤者送往医院抢救时，途中尽量减少颠簸，同时密切注意伤者的呼吸、脉搏、血压及伤口的情况。

**报警电话及内容：**

（1）电话：公司 24 小时值班电话 `{{COMPANY_24H_PHONE}}`；火灾报警 119；三警合一报警 110；急救中心 120。

（2）应报告以下内容：报警单位名称、发生事故的时间、地点、事故的类型、发展和蔓延情况、现场处置和控制情况、引起伤害及人员伤亡等内容。

## 注意事项

1）抢险人员必须佩戴好个人防护用品进入危险场所进行抢险和救护.

2）实施抢险救援时应先救人再实施其他抢险.

3）现场救护与抢险相结合，如没有相应个人防护用品，不得盲目抢险和救护。

4）现场施救人员应具备相应知识和能力，确保抢险和救治得体有效.

5）设立警戒区防止无关人员进入危险区。
