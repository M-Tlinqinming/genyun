# 其他伤害事故现场处置方案

## 事故风险描述

（1）事故类型：本方案为兜底性处置方案，适用于不能归入前列各类事故的其他伤害情形，主要包含骨折、休克、坍塌、中暑等场景的现场急救处置。

[[if:expertArea]]
（2）事故区域：{{HAZARD_AREA}}。
[[endif]]
[[if:!expertArea]]
（2）事故区域：生产车间、仓库、料场、作业平台、高温作业区、户外装卸场所等。
[[endif]]

（3）事故基本征兆及条件：操作人员违反操作规程、个人防护用品穿戴不到位、作业环境存在潜在危险因素（堆放超高、高温环境、湿滑地面等）、设备设施缺陷或突发意外事件，均可能引发骨折、失血性休克、物料坍塌、中暑等伤害。

（4）事故可能造成的危害程度：造成人员伤残、昏迷、休克甚至死亡，严重时可能引发其他安全生产事故。

## 应急工作职责

### 应急组织形式及人员

由现场班组长和现场员工组成。无现场班组长的，由现场职务最高的员工或对事发区域负有安全责任的员工为现场负责人。

### 主要职责

**现场负责人职责：**

（1）无论在任何时候发生事故，现场负责人首先进入指挥岗位，做好应急处置工作，并安排将情况报告总指挥或副总指挥。

（2）估算事故的严重性及危害程度，现场应急力量是否有足够的能力进行处理，决定是否报告总指挥或副总指挥申请应急响应。

（3）如能有足够的人力物力处理事故，必须迅速调动相应的人力物力展开应急救援工作。

（4）如明确事故属于现场处置力量难以控制或人员难以救护性质的，则及早安排将重要物资、人员撤离现场到安全地带，及早拨打"120"请求救护。

**现场应急救援人员职责：** 听从现场负责人的指挥，进行应急处置及现场急救等工作。

## 应急处置

### 骨折现场处置

（1）有骨折者应予以固定；有出血时应紧急止血；有颅脑、胸腹部损伤者，必须给予相应处理，并及时送医院救治。

（2）迅速送往医院救治。伤员经现场简易急救后，应尽快送往临近医院救治。护送前及护送途中要注意防止休克。搬运时动作要轻柔，行动要平稳，以尽量减少伤员痛苦。

### 休克现场处置

休克是由于严重创伤、烧伤、触电、骨折的剧烈疼痛和大出血等引起的一种威胁伤员生命、极危险的严重综合症。虽然有些伤不能直接置人于死地，但如果救治不及时，其引起的严重休克常常可以使人致命。休克的症状是口唇及面色苍白、四肢发凉、脉搏微弱、呼吸加快、出冷汗、表情淡漠、口渴，严重者可出现反应迟钝，甚至神志不清或昏迷，口唇肢端发绀，四肢冰凉，脉搏摸不清，血压下降，无尿。预防休克和休克急救的主要方法是：

（1）尽快发现和抢救受伤人员，及时妥善地包扎伤口，减少出血、污染和疼痛。尤其对骨折、大关节伤和大块软组织伤，要及时地进行良好的固定。一切外出血都要及时有效地止血。凡确定有内出血的伤员，要迅速送往医院救治。

（2）对急救后的伤员，要安置在安全可靠的地方，让伤员平卧休息，并给予亲切安慰和照顾，以消除伤员思想上的顾虑。待伤员得到短时间的休息后，急送医院治疗。

（3）对有剧烈疼痛的伤员，要服止痛药。

（4）对没有昏迷或无内脏损伤的伤员，要多次少量给予饮料，如姜汤、米汤、热茶水或淡盐水等。此外，冬季要注意保暖，夏季要注意防暑，有条件时要及时更换潮湿的衣服，使伤员平卧，保持呼吸通畅，必要时还应做人工呼吸。

### 坍塌事故现场处置

如料场、仓库、生产车间堆放产品堆放超高，或堆放、装卸货过程违规作业，厂内机动车运输车意外碰撞厂区内建筑物引发坍塌，可能造成现场人员被坍塌物击伤、残疾、重伤或引发再次事故的发生等。

（1）事故现场发现人员立即通知现场负责人，并停止相关作业。

（2）发现伤员在确保自身安全的情况下，立即进行抢救。

（3）视事故情况迅速隔离事发现场，撤离易燃易爆物资，以免引发火灾事故，撤离受坍塌威胁的人员。

（4）受威胁区域的人员，在发生事故后应根据现场情况，在保证自身安全的情况下，采取积极有效的方法进行自救和互救。

### 中暑现场处置

高温中暑的症状：在高温环境下活动一段时间后，出现乏力、大量出汗、口渴、头痛、头晕、眼花、耳鸣、恶心、胸闷、体温正常或略高。

轻症中暑，临床表现为头昏、头痛、面色潮红、口渴、大量出汗、全身疲乏、心悸、脉搏快速、注意力不集中、动作不协调等症状，体温升高至 38.5℃ 以上。

重症中暑，包括热射病、热痉挛和热衰竭三种类型。

高温中暑急救的主要方法是：

（1）作业人员感觉到头痛、心慌时应立即到阴凉处休息、饮水。

（2）及时脱离高温环境，迅速将病人移到阴凉、通风地方，垫高头部，解开衣扣，平卧休息，观察体温、脉搏、呼吸、血压变化。

（3）用冷水毛巾敷头部，或用冰袋置于中暑者头部和大腿根部等部位，或用 30% 酒精擦身降温，并补充淡盐水、冷西瓜水、绿豆汤等含盐清凉饮料，清醒者也可服人丹、十滴水、藿香正气水等。

（4）对日射病者应严密观察意识、瞳孔等变化，头置冰袋或冰帽，以冷水洗面及颈部，以降低体表温度；有意识障碍呈昏迷者，要注意防止因呕吐物误吸而引起窒息，将病人的头偏向一侧，保持其呼吸道通畅。

（5）对重症中暑者应立即送往医疗机构进行治疗。

### 报警电话及报警内容

（1）电话：公司 24 小时值班电话 `{{COMPANY_24H_PHONE}}`；火灾报警 119；三警合一报警 110；急救中心 120。

（2）应报告以下内容：报警单位名称、发生事故的时间、地点、事故的类型、发展和蔓延情况、现场处置和控制情况、伤害情况及人员伤亡等内容。

## 注意事项

（1）救援时应先确保自身安全，再对伤员实施救护；必须采取防止二次伤害的安全措施。

（2）不得随意搬动脊柱或颅脑受伤人员，应在初步固定后再搬运，防止受损脊柱压迫中枢神经。

（3）骨折伤员的创面应避免再次污染，附着异物暂不去除，待送医院后处理。

（4）高温作业场所应配备足量清凉饮料和急救药品，加强轮休制度和饮水补充，预防中暑。

（5）坍塌事故救援现场应确认结构稳定后再进入，防止二次坍塌。
