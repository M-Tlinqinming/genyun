# 坍塌事故现场处置方案

## 事故风险描述

（1）事故类型：建筑物、构筑、堆置物的等因设计或施工不合理而造成的倒塌，钢架棚体坍塌，有可能会造成人员伤害、伤亡的事故。

（2）事故区域：建筑物、构筑、堆置物等。

（3）事故基本征兆及条件：因设计或施工不合理，操作员违规操作。

（4）事故可能造成的危害程度：伤残疾、重伤或次生事故的发生等。

## 应急工作职责

### 应急组织形式及人员

由现场班组长和现场员工组成。无现场班组长的，由现场职务最高的员工或对事发区域负有安全责任的员工为现场负责人。

### 主要职责

**现场负责人职责：**

（1）无论在任何时候发生事故，现场负责人首先进入指挥岗位，做好应急处置工作，并安排将情况报告总指挥或副总指挥。

（2）估算事故的严重性及危害程度，现场应急力量是否有足够的能力进行处理，决定是否报告总指挥或副总指挥申请应急响应。

（3）如能有足够的人力物力处理事故，必须迅速调动相应的人力物力展开应急救援工作。

（4）如明确事故属于现场处置力量难以控制或人员难以救护性质的，则及早安排将重要物资、人员撤离现场到安全地带。

**现场应急救援人员的职责：**

现场应急人员的主要职责是听从现场负责人的指挥，进行应急处置及现场急救等工作。

## 应急处置

### 事故应急处置

（1）当发生坍塌事故时，在事故发生点100m范围内划定危险区域，疏散人群，减少不必要伤亡。

（2）积极抢救现场受伤人员，将受伤人员疏散至安全地点进行救护。如现场有人员被埋，现场指挥人员和抢救人员，应根据事故具体情况，采取机械和人工相结合的办法，对坍塌现场进行处理，在接近被埋人员时必须停止机械作业，改用人工挖掘，防止误伤被埋人员。

### 现场急救

（1）如伤员发生休克，先处理休克，处于休克状态的伤员要让其安静、保暖、平卧、少动，并将下肢抬高约20度左右。

（2）遇呼吸、心跳停止者，立即进行人工呼吸。

（3）出现颅脑损伤，必须维持呼吸道通畅。昏迷者应平卧，面部转向一侧，以防舌根下坠或分泌物、呕吐物吸入，发生喉阻塞。有骨折者，应初步固定后再搬运。遇有凹陷骨折，严重的颅骶骨及严重的脑损伤症状出现，创伤处用消毒的纱布或清洁布等覆盖伤口，用绷带或布条包扎。

（4）遇脊椎受伤者，创伤处用消毒的纱布或清洁布等覆盖伤口，用绷带或布条包扎后，搬运时，将伤者平卧放在帆布担架或硬板上，以免受伤的脊椎移位、断裂造成截瘫或致死亡。抢救脊椎受伤者，搬运过程，严禁只抬伤者的两肩与两腿或单肩脊运。

（5）发现伤者手足骨折，不要盲目搬运伤者。应在骨折部位用夹板把受伤位置临时固定，使断端不再移位或刺伤肌肉、神经或血管。固定方法：以固定骨折处上、下关节为原则，可就地取材，用木板、竹头等。无材料的情况下，上肢可固定在身侧，下肢与健侧下肢缚在一起。

（6）遇有创伤性出血的伤员，迅速包扎止血，使伤员保持在头低脚高的卧位。

### 报警电话及报警内容

（1）电话：公司 24 小时值班电话 `{{COMPANY_24H_PHONE}}`；火灾报警 119；三警合一报警 110；急救中心 120。

## 注意事项

**佩戴个人防护器具、使用抢险救援器具、采取救援对策方面注意事项：**

（1）作业前应评估抢险场所可能潜在之危害，如果有危险存在，应提供何种有效的个人防护器具、抢险救援器具，并正确选择和使用；

（2）进入现场人员必须配备必要的个人防护器具进入现场；

（3）所有现场采取的救援对策和措施应经危害辩识和评估确保安全的情况下方可采用，严禁个人未经现场指挥人员同意随意采取救援行动。

**现场自救和互救注意事项：**

（1）发生事故时，应第一时间报警；

（2）进入现场抢险救人之前，要根据个人自身的能力，在本身能力没有一定把握的情况下和无防护装备的情况下不要贸然行事；

（3）事故扩大时，切勿贪恋财物或存侥幸心理拖延逃离时间。

**应急救援结束后的注意事项：**

（1）坍塌事故发生后，在救援前，一定要确保没有第二次坍塌或有坍塌时也影响不到营救范围时才能进行抢救人员的行动，避免人员受到二次坍塌的伤害；

（2）如有人员失踪要马上清点人数，向知情人员了解失踪人员被埋的位置，只要有可能，现场管理人员第一时间应组织人员抢救被埋人员，避免延误抢救时间，引起被埋人员窒息造成伤害；

（3）应急救援结束后，应派专人全面彻底检查，确认危险已经彻底消除，防止其他危险隐患存在。
