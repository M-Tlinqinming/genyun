# 坍塌事故现场处置方案

## 事故风险描述

（1）事故类型：建构筑物（厂房、围墙、料仓、临时构筑物等）、堆置物（成品堆、原材料堆、托盘垛）、基坑/边坡作业面、脚手架及模板支撑系统等，因设计缺陷、施工不当、超载、操作违规或自然灾害（暴雨、地震、强风）等原因，发生整体或局部失稳、塌落、垮塌、滑塌的事故。

（2）事故区域：仓库及堆场、基坑/边坡作业区、脚手架及模板支撑作业区、料仓料垛区、临时构筑物及围墙、地下管沟作业区等存在结构荷载或堆压荷载的场所。

（3）事故基本征兆及条件：堆垛超高超重、堆放无序、底层托盘破损；基坑边坡未按方案放坡、支护失效、排水不畅；脚手架立杆扣件松动、剪刀撑缺失、超载使用；强降雨/连续阴雨/化雪后未做安全确认；爆破/打桩/重型机械振动；构筑物出现新增裂缝、表面变形、下沉、漏水、扬尘、异响等先兆。

（4）事故可能造成的危害程度：人员被埋、被压、窒息、骨折、内脏损伤、断指（肢），严重时造成人员死亡，并可能引发次生事故（火灾、泄漏、电击、有毒/可燃气体逸散）。

## 应急工作职责

### 应急组织形式及人员

由现场班组长、抢险救灾组、警戒疏散组成员和现场员工组成。无现场班组长的，由现场职务最高的员工或对事发区域负有安全责任的员工为现场负责人。

### 主要职责

**现场负责人职责：**

（1）无论在任何时候发生事故，现场负责人首先进入指挥岗位，做好应急处置工作，并安排将情况报告总指挥或副总指挥。

（2）按现场坍塌规模划定不少于 100m 半径的警戒范围，禁止无关人员进入；估算事故的严重性及危害程度，决定是否报告总指挥或副总指挥申请应急响应。

（3）如能有足够的人力物力处理事故，必须迅速调动相应的人力物力展开应急救援工作。

（4）如明确事故属于现场处置力量难以控制（如大型建构筑物坍塌、被埋人员需专业破拆装备）的，则及早安排将重要物资、人员撤离现场到安全地带，并联系 `{{FIRE_DEPT_NAME}}`（电话 `{{FIRE_DEPT_PHONE}}`）和 120 急救等外部专业力量到场。

**抢险救灾组职责：**

（1）必须在确认结构稳定、无二次坍塌风险后才进入事故区域；进入前评估是否需要先行临时支撑（顶撑、拉撑）。

（2）按"先表层后深层、先轻型物后重型物、先人工后机械"的顺序清除堆压物，避免野蛮挖掘加剧次生坍塌。

（3）配合医疗救护人员实施止血、骨折固定、断指（肢）保护等现场急救。

**警戒疏散组职责：** 拉警戒线、设警示标志、引导通道车辆改道、严控围观人员；持续观察周围结构变形、新增裂缝、异响等次生坍塌征兆，及时向现场负责人通报。

**现场应急救援人员职责：** 听从现场负责人的指挥，进行应急处置及现场急救等工作。

## 应急处置

### 撤离与警戒

（1）听到坍塌声响或发现先兆（异响、裂缝扩展、新增下沉、扬尘）时立即撤离作业区，原地停止机械作业，切断作业电源、气源。

（2）现场负责人按坍塌规模划定不少于 100m 半径的警戒区，无关人员撤至上风向、地势较高且远离裂缝/沉陷的安全地带集合清点。

（3）安排专人监视周围结构、地面、堆置物，发现异响、裂缝扩展、新增下沉立即扩大警戒范围、暂停救援作业。

### 被埋人员搜寻与救援

（1）通过呼喊、敲击、叩击管线等方式与被埋人员保持联系，登记被埋人员人数、位置、伤情。

（2）救援按"先表层、后深层；先轻型物、后重型物；先手工、后机械"的顺序进行；切割重型构件须二人监护、设置临时支撑。

（3）暴露伤员后先供给空气和水（清醒者），评估伤情，按医疗救护程序处置；不可强行牵拉被压肢体，防止挤压综合征。

### 医疗救护

（1）不要轻易移动受伤者，先评估意识、呼吸、脉搏；若呼吸心跳停止，立即施行心肺复苏（人工呼吸 + 胸外按压）。

（2）出血时有效止血、加压包扎；骨折用夹板/木板/绷带等固定，避免随意搬动脊柱。

（3）发生断指（肢）应立即止血，尽可能将断指（肢）冲洗干净，用消毒敷料袋包好，放入装有冷饮的塑料袋外侧（不可直接接触冰水），与伤者一并送往医院。

（4）伤员转运优先实施脊柱保护（整体平移、硬质担架）。

### 报警电话及报警内容

（1）电话：公司 24 小时值班电话 `{{COMPANY_24H_PHONE}}`；三警合一报警 110；急救中心 120；火灾联动报警 119；辖区消防大队 `{{FIRE_DEPT_NAME}}` `{{FIRE_DEPT_PHONE}}`（涉及大型构筑物坍塌、被埋人员、需专业破拆/救援装备时同步报警）。

（2）应报告以下内容：报警单位名称、发生事故的时间、地点、事故的类型（坍塌）、坍塌部位与规模、被埋人数估算、有无次生事故（火灾/泄漏/电击）、现场处置和控制情况、人员伤亡等内容。

## 注意事项

（1）救援前必须确认结构稳定，必要时先做临时支撑（顶撑、拉撑），严禁未做监护即进入坍塌区救人，防止二次坍塌。

（2）暴雨、连续阴雨或化雪后开挖、临边作业前，应重新核查支护、排水状态，未恢复安全条件不得复工。

（3）重型机械（吊车、挖掘机）作业必须由专人指挥、避开被埋人员可能位置；严禁以机械抓扒方式进行被埋人员搜救末段作业。

（4）抢险人员必须佩戴安全帽、护目镜、防尘口罩等个体防护用品，长时间作业实施轮换；涉及料仓、地下空间时持续监测有毒/可燃气体浓度。

（5）现场保持有效通讯，控制进入坍塌区域的人员数量，与被埋人员保持语言或敲击信号联系直至救出。
