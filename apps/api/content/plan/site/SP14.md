# 窒息事故现场处置方案

## 事故风险描述

（1）事故类型：化学品储存使用场所，因化学品泄漏逸散，使环境缺氧，导致作业人员窒息。

（2）事故风险区域：化学品储存使用场所等相对密闭且会产生有毒有害气体的场所。

（3）事故前可能出现的征兆及条件：呕吐、脸色仓白、冒冷汗、头晕头痛、恶心、口吐白沫、呼吸急促等。

（4）事故可能造成的危害程度：窒息事故抢救不及时可致人死亡，因施救不当会扩大伤亡人数。

## 应急工作职责

### 应急组织形式及人员

由现场班组长和现场员工组成。有现场班组长的，现场班组长为现场负责人，无现场班组长的，由现场职务最高的员工或对事发区域负有安全责任的员工为现场负责人。

### 主要职责

**现场负责人职责：**

（1）无论在任何时候发生事故，现场负责人首先进入指挥岗位，做好应急处置工作，并安排将情况报告总指挥或副总指挥。

（2）评估事故的严重性及危害程度，现场应急力量是否有足够的能力进行处理，决定是否报告总指挥或副总指挥申请应急响应。

（3）如能有足够的人力物力处理事故，必须迅速调动相应的人力物力展开应急救援工作。

（4）如明确事故属于现场处置力量难以控制或人员难以救护性质的，则及早安排将重要物资、人员撤离现场安全地带。

**现场应急救援人员的职责：**

现场应急人员的主要职责是听从现场负责人的指挥，进行应急处置及现场急救等工作。

## 应急处置

**1）事故应急处置**

（1）应迅速对周围环境进行确认，仍存在危险因素下，立即组织人员防护，并禁止无关人员进入。

（2）使用检测仪器对有限空间有毒有害气体的浓度和氧气的含量进行检测，氧浓度（应在19.5-23.5%范围内），易燃/可燃气体浓度（应&lt; 最低爆炸极限的10%），有毒有害气体如一氧化碳浓度（应&lt;24ppm）；

（3）抢险人员要穿戴好必要的劳动防护用品（正压式空气呼吸器、防静电工作服、工作帽、手套、工作鞋、安全绳等），系好安全带，以防止抢险救援人员受到伤害。受限空间内抢险人员与外面监护人员应保持通讯联络畅通并确定好联络信号，在抢险人员撤离前，监护人员不得离开监护岗位。

（4）加强通风换气等相应的措施，确保整个救援期间处于安全受控状态；在伤情允许情况下，采取防护措施后将受伤人员救离现场，转移到安全地方。

（5）在伤情允许情况下，采取防护措施后将受伤人员救离现场，转移到安全地方，如果停止呼吸应立即进行人工呼吸，如果心跳停止应立即进行心脏胸外挤压等。

**2）报警（电话）及报警内容：**

（1）电话：公司 24 小时值班电话 `{{COMPANY_24H_PHONE}}`；火灾报警 119；三警合一报警 110；急救中心 120。

（2）应报告以下内容：报警单位名称、发生事故的时间、地点、事故的类型、发展和蔓延情况、现场处置和控制情况、引起的中毒窒息及人员伤亡等内容。

## 注意事项

（1）在发生事故后应根据现场情况，在保证自身安全的前提下，采取积极有效的方法进行救援。

（2）救援时必须有专人在现场周围监护，进入现场营救的人员必须有防护用品。
