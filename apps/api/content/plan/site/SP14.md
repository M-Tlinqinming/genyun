# 窒息事故现场处置方案

## 事故风险描述

（1）事故类型：使用惰性气体的场所（如焊接保护气、激光切割保护气、热处理保护气、食品包装充氮、低温液氮罐、二氧化碳灭火系统等），因气瓶或管路阀门泄漏、储罐安全阀误动作等导致氮气、氩气、二氧化碳等惰性气体扩散，置换作业区氧气，使作业人员陷入缺氧环境而发生窒息。

（2）事故区域：焊接（保护气）作业区、激光切割车间、惰性气体气瓶储存间、食品充氮包装线、低温液化气体储罐区等。

（3）事故基本征兆及条件：员工出现头晕、乏力、脸色苍白、冒冷汗、呼吸急促、口唇发绀、意识模糊或突然晕倒等缺氧症状；惰性气体气瓶或管路有泄漏声响、结霜（液氮、液态二氧化碳泄漏）；通风不良；作业现场无气体浓度监测装置或装置失效；个人防护装备缺失。

（4）事故可能造成的危害程度：窒息事故抢救不及时可在数分钟内致人死亡；惰性气体无色、无味、无刺激性，作业人员往往无明显先兆即陷入昏迷；因施救不当（未佩戴正压式空气呼吸器贸然进入）极易扩大伤亡人数。

## 应急工作职责

### 应急组织形式及人员

由现场班组长和现场员工组成。有现场班组长的，现场班组长为现场负责人；无现场班组长的，由现场职务最高的员工或对事发区域负有安全责任的员工为现场负责人。

### 主要职责

**现场负责人职责：**

（1）无论在任何时候发生事故，现场负责人首先进入指挥岗位，做好应急处置工作，并安排将情况报告总指挥或副总指挥。

（2）评估事故的严重性及危害程度，现场应急力量是否有足够的能力进行处理，决定是否报告总指挥或副总指挥申请应急响应。

（3）如能有足够的人力物力处理事故，必须迅速调动相应的人力物力展开应急救援工作。

（4）如明确事故属于现场处置力量难以控制或人员难以救护性质的，则及早安排将重要物资、人员撤离现场到安全地带。

**现场应急救援人员职责：**听从现场负责人的指挥，进行应急处置及现场急救等工作。

## 应急处置

### 事故应急处置

（1）应迅速对周围环境进行确认，仍存在缺氧危险时，立即组织人员防护，并禁止无关人员进入。

（2）使用便携式氧含量检测仪对作业区进行检测：氧浓度应在 19.5%–23.5% 范围内方为安全；低于该范围时，作业区视为缺氧，严禁未防护进入。

（3）抢险人员进入前必须穿戴好正压式空气呼吸器、防静电工作服、工作帽、手套、工作鞋、安全绳等，并系好安全带；现场设监护人员，与抢险人员保持通讯联络畅通并确定好联络信号；在抢险人员撤离前，监护人员不得离开监护岗位。

（4）切断惰性气体源：关闭气瓶阀门、关闭管路截止阀；对低温液化气体（液氮、液态二氧化碳）泄漏，按设备应急操作规程关闭储罐输出阀。

（5）通风换气：立即开启所有门窗、机械排风系统，加大通风换气量；如条件允许，开启厂房应急排风装置，将惰性气体快速稀释至安全浓度（氧浓度恢复至 19.5% 以上）。

（6）救出窒息人员：在通风换气与持续监测的同时，由佩戴正压式呼吸器的抢险人员进入，将窒息人员转移到空气新鲜处，解开伤员衣领，保持其呼吸道通畅。

（7）现场急救：如停止呼吸应立即进行人工呼吸；如心跳停止应立即进行胸外按压；有条件时给予氧气吸入；急救持续至专业救护人员接手。

### 报警电话及报警内容

（1）电话：公司 24 小时值班电话 `{{COMPANY_24H_PHONE}}`；三警合一报警 110；急救中心 120。

（2）应报告以下内容：报警单位名称、发生事故的时间、地点、事故的类型、发展和蔓延情况、现场处置和控制情况、引起的窒息事故及人员伤亡等内容；尤其需说明涉及的惰性气体种类（氮气/氩气/二氧化碳等），便于 120 准备复苏与供氧设备。

## 注意事项

（1）在发生事故后应根据现场情况，在保证自身安全的前提下，采取积极有效的方法进行救援。

（2）救援时必须有专人在现场周围监护；进入现场营救的人员必须佩戴正压式空气呼吸器，严禁仅凭防尘口罩、活性炭口罩或长管呼吸器（在缺氧环境下不可靠）贸然进入。

（3）惰性气体（氮气、氩气、二氧化碳）无色、无味，不可凭感官判断浓度；进入前必须用气体浓度检测仪确认氧浓度达标。

（4）密闭空间（污水池、地下储罐、有限空间作业等）内的窒息事故按 P4 有限空间专项应急预案处置，本方案不重复覆盖密闭空间场景。

（5）惰性气体严重泄漏可能伴生低温伤害（液氮、液态二氧化碳泄漏导致冻伤），救援人员需穿戴防冻护具。
