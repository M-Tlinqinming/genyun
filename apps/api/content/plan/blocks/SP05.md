# 容器爆炸事故现场处置方案

## 事故风险描述

（1）事故类型：公司生产、辅助系统涉及多类压力容器，包括 {{slot:pressure-vessels}}。因罐体老化、安全附件失灵、维护保养不当、员工违规操作等导致超压，可发生容器爆炸；爆炸产生的高温可能引燃周围可燃、易燃物，伴生火灾。

（2）事故区域：空压机房、压力容器存储与使用场所。

（3）事故基本征兆及条件：

1）员工违规操作；压力容器受压元件出现裂纹、严重腐蚀、变形、组织变化等缺陷；

2）安全阀、压力表等安全装置失灵；安全阀自动泄压，压力表指针指示超压。

（4）事故可能造成的危害程度：可能导致人员伤亡（爆炸冲击波伤、烫伤、烧伤、断肢等）、损坏设备、设施、厂房；高温汽水冲出与可能引发的二次燃烧、二次爆炸将进一步扩大危害范围。

## 应急工作职责

### 应急组织形式及人员

由现场班组长和现场员工组成。无现场班组长的，由现场职务最高的员工或对事发区域负有安全责任的员工为现场负责人。

### 主要职责

**现场负责人职责：**

（1）无论在任何时候发生事故，现场负责人首先进入指挥岗位，做好应急处置工作，并安排将情况报告总指挥或副总指挥。

（2）评估事故的严重性及危害程度，现场应急力量是否有足够的能力进行处理，决定是否报告总指挥或副总指挥申请应急响应。

（3）如能有足够的人力物力处理事故，必须迅速调动相应的人力物力展开应急救援工作。

（4）如明确事故属于现场处置力量难以控制或人员难以救护性质的，则及早安排将重要物资、人员撤离现场到安全地带。

**设备操作员职责：**

压力容器操作人员：发现异常立即按操作规程紧急停机、切断电源、按程序泄压。

**现场应急救援人员职责：**听从现场负责人的指挥，进行应急处置及现场急救等工作。

## 应急处置

### 应急处置原则

救人第一的原则——若事故中有人员受到伤害或威胁，首要任务是救人，决不能因其他原因而耽误救人时机。

### 应急处置程序

发生容器爆炸事故，现场人员应立即将事故报告班（组）长，组长报应急总指挥和副总指挥。报警内容应包括：

（1）发生事故的时间；

（2）发生事故的具体部位（容器类型）；

（3）事故具体类型（容器超压爆炸 / 二次燃烧等）；

（4）事故范围、规模；

（5）人员受伤或失踪情况；

（6）次生灾害情况（伴生火灾、可燃气体泄漏、邻近设备受损等）。

### 现场应急处置措施

（1）现场人员应迅速趴下、躲入墙体背后，以躲避冲击波，并防止热水、蒸汽等烧烫伤；沿疏散路线迅速逃离危险区，撤至安全地点后立即汇报班（组）长。

（2）切断电源与能源：关闭压力容器配套电气电源（如空压机电源）；燃料管道泄漏时立即切断进料阀门。

（3）通用压力容器（{{slot:pressure-vessels}}）泄压处置：在保证个人安全的前提下，按设备操作规程打开安全阀、堵头、阀门进行泄压；打开门窗通风，查找泄漏源进行堵漏；将周围可燃、易燃物迅速隔离。

（4）严重爆炸情形——按消防要求正确灭火（容器爆炸常伴生火灾，由现场负责人按 SP01 火灾事故现场处置方案联动），防止周边易燃、易爆物二次爆炸燃烧；同步抢救受困、受伤人员。

（5）警戒与隔离：在事故区域外设置警戒线（爆炸冲击半径外延 30m 以上），防止无关人员进入。

### 医疗救护措施

（1）不要轻易移动受伤者，保持其呼吸道通畅；

（2）有出血时，应有效止血、包扎伤口（视情况采用包扎法、加压包扎法、指压法）；

（3）如果发生骨折，用双手稳定及承托受伤部位，限制骨折处活动并设置软垫，用绷带、夹板或替代品妥善固定伤肢；搬动伤员时勿使伤处移位、扭曲、震动；

（4）发生断指（肢）应立即止血，尽可能将断指（肢）冲洗干净，用消毒敷料袋包好，放入装有冷饮的塑料袋内，与伤者一并立即送往医院；

（5）对失去知觉者，宜清除口鼻中的异物、分泌物、呕吐物，将伤员置于侧卧位以防窒息；

（6）如果伤者出现呼吸或心跳停止，应立即施行人工呼吸和胸外心脏按压，并速送医院；对严重创伤伤员（大出血、多发性创伤、断肢等），等待专业人员救护。

### 报警电话及报警内容

（1）电话：公司 24 小时值班电话 `{{COMPANY_24H_PHONE}}`；火灾报警 119（容器爆炸常伴生火灾，119 同步报警）；急救中心 120；三警合一报警 110；辖区消防大队 `{{FIRE_DEPT_NAME}}`"`{{FIRE_DEPT_PHONE}}`"。

（2）应报告以下内容：报警单位名称、发生事故的时间、地点、事故的类型（容器爆炸）、发展和蔓延情况、是否伴生火灾或可燃气体泄漏、现场处置和控制情况、引起的容器爆炸及人员伤亡等内容。

## 注意事项

（1）受伤者伤势严重时，不要轻易移动伤者；抢救伤员时必须配戴好个人防护用品（防护服、防护鞋、防护面罩等）。

（2）在未切断空压机电源、未采取泄压措施前，任何人不得进入现场；如有起火，在没有采取堵漏措施前，不可强行扑灭气体管道泄漏的稳定燃烧（应保持稳定燃烧并冷却容器，防止燃料喷射至空气中形成爆炸性混合物）。

（3）抢险人员必须佩戴好个人防护用品进入危险场所进行抢险和救护；如没有相应个人防护用品，不得盲目抢险和救护；现场救护与抢险相结合，先救人再实施其他抢险。

（4）现场施救人员应具备相应知识和能力，确保抢险和救治得体有效。

（5）设立警戒区（爆炸冲击半径外延 30m 以上），防止无关人员进入危险区；伴生火灾时按 SP01 联动处置。
