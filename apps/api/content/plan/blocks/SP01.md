# 火灾事故现场处置方案

## 事故风险描述

（1）事故类型：生产车间、仓库存在大量可燃物，电气设备过载 / 短路 / 接触不良产生的高温熔化物掉落、机械维修摩擦发热引燃周围可燃易燃物可导致火灾；压铸熔炉与压铸区高温熔融金属（{{slot:melt-types}}）飞溅引燃邻近可燃物；压铸机高压液压油泄漏喷射遇火；化学品柜内小量{{slot:flammable-liquids}}遇明火火花引燃；抛光 / 喷砂工序沉积粉尘遇火高温扰动二次燃爆。

（2）事故区域：压铸车间（熔炉 / 压铸机区）、抛光 / 喷砂工位、化学品柜存放区、仓库及辅助用房等。

（3）事故基本征兆及条件：易燃物品遇热源、电气机械火花、静电火花、熔融金属飞溅、液压油喷射、积尘扬尘或人为事故等。

（4）事故可能造成的危害程度：人员烧伤、中毒窒息、伤亡，损坏设备、厂房等。

## 应急工作职责

### 应急组织形式及人员

由现场班组长、医疗救护人员、现场员工组成。无现场班组长的，由现场职务最高的员工或对事发区域负有安全责任的员工为现场负责人。

### 主要职责

**现场负责人职责：**无论在任何时候发生事故，现场负责人应首先进入指挥岗位，做好应急处置工作并将情况报告总指挥或副总指挥；估算事故严重性及危害程度，决定是否申请外部救援力量支援；如能有足够人力物力处理事故，迅速调动展开应急救援；如明确属于现场处置力量难以控制或人员难以救护性质的，及早安排重要物资、人员撤离到安全地带，情况危急时拨打 `{{FIRE_DEPT_NAME}}`"`{{FIRE_DEPT_PHONE}}`"、120、110 请求支援。

**医疗救护人员职责：**迅速将伤员撤离火场，置于通风良好处，清除口鼻分泌物和碳粒，保持呼吸道通畅，有条件时通过导管给氧，判断是否有一氧化碳等窒息性物质中毒可能，及时送医并途中严密观察防止窒息。

**现场应急救援人员职责：**听从现场负责人的指挥，进行应急处置及现场急救等工作。

## 应急处置

### 灭火基本原则

扑救初起火灾时，必须遵循：先控制后消灭，救人第一，先重点后一般的原则。先控制后消灭是指对于不能立即扑救的火灾，要首先控制火势的继续蔓延和扩大，在具备扑灭条件时再展开全面扑救；救人第一是指火场上如有人受火势围困，应急人员首要任务是把受困人员抢救出来，可视情况救火与救人同时进行；先重点后一般是指对事关全局或生命安全的物资和人员优先抢救。一般火灾迅速隔离周围可燃易燃物，就近取灭火器扑救；电气火灾立即切断灾区电源，用干粉灭火器扑救（不得使用水），由熟悉带电设备的技术人员负责灭火指挥。

### 高温熔融金属等特殊火灾场景处置

本企业涉及{{slot:melt-types}}等高温熔融金属作业，火灾扑救还须执行以下措施：

（1）熔炉及熔融金属作业区高温熔融金属（{{slot:melt-types}}）引燃可燃物的火灾：🛑 严禁用水扑救与熔融物直接接触或邻近的可燃物——水流接触熔融物瞬间汽化、体积急剧膨胀，将引发二次蒸气爆炸；应使用干粉灭火剂、干燥沙土覆盖扑救，远离熔融物的可燃物火灾才可常规扑救。

（2）压铸机液压油火灾：压铸机等高压液压系统的液压油（矿物油）泄漏或受压喷射遇火属 B 类火灾，应立即切断液压泵站动力源，用泡沫、干粉或二氧化碳灭火剂扑救；严禁用直流水柱直接冲击高压油喷射点——高压油雾遇水柱飞溅会扩大燃烧面、加剧立体燃烧。

（3）化学品柜酒精火灾：化学品柜内小量{{slot:flammable-liquids}}等水溶性可燃液体火灾，应使用抗溶性泡沫、干粉或二氧化碳灭火剂扑救，并移走柜内邻近可燃物；严禁用直流水冲击流淌的酒精液面——水不能稀释酒精灭火，反而冲散流淌火、扩大火势。

（4）抛光 / 喷砂积尘二次燃爆：抛光、喷砂等工序在设备表面与地面沉积的粉尘，在火灾高温与气流扰动下可被卷扬形成粉尘云发生二次燃爆；扑救时严禁用高压水枪或压缩空气直吹积尘部位，应采用低压雾化水或先湿润再清理，并切断引燃源、隔离产尘区，防止二次爆炸伤人。

### 疏散措施

（1）现场负责人确认发生危及员工人身安全的事故时，应立即向上报告并立即组织员工疏散；综合保障组用最快速度通知现场无关人员按疏散指示标志、就近原则向集合点有序撤离。

（2）当抢险救灾组或有关部门（如消防队）到达事故现场后，现场负责人和工作人员主动汇报事故现场情况，指挥权上移后积极协助做好疏散抢救工作。

### 报警电话及报警内容

（1）电话：公司 24 小时值班电话 `{{COMPANY_24H_PHONE}}`；火灾报警 119；三警合一报警 110；急救中心 120；辖区消防大队 `{{FIRE_DEPT_NAME}}`"`{{FIRE_DEPT_PHONE}}`"。

（2）应报告以下内容：报警单位名称、发生事故的时间、地点、事故的类型、发展和蔓延情况、现场处置和控制情况、引起火灾事故及人员伤亡等内容。

## 注意事项

（1）灭火人员进行火灾扑救时应站在上风位置，保持必要安全距离，配戴好必要的个体防护用品，当火势过大可能危及救护人员安全时迅速撤离现场；

（2）扑救电气火灾时禁止用水灭火；迅速转移隔离化学品防止火灾扩大；

（3）采取有效措施扑灭身上火焰使伤员迅速脱离致伤现场。衣服着火时应水浸、水淋、就地卧倒翻滚等尽快灭火，千万不可直立奔跑或站立呼喊，以免助长燃烧、引起或加重呼吸道烧伤；灭火后如衣服与皮肤粘在一起，可在救护人员帮助下把未粘部分剪去并对创面包扎；

（4）保护创面，尽量不要弄破水泡，不能涂龙胆紫一类有色外用药，对创面立即用三角巾、大纱布块、清洁衣物等给予简单确实的包扎，手足烧伤时各指、趾分开包扎以防粘结。
