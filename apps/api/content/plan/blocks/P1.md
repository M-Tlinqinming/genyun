# 火灾爆炸事故专项应急预案

## 适用范围

本专项应急预案适用于公司管辖范围内因电气故障、明火作业、自燃、外部引火、压铸熔融金属引燃、压铸机液压油泄漏、化学品柜酒精、抛光 / 喷砂积尘等引发的火灾事故的应急处置；适用于事故初始阶段，或现场班组应急力量无法有效处置的较大事故的应急处置。本预案与综合应急预案衔接使用，火灾以外的爆炸类事故（容器爆炸、粉尘爆炸、可燃气体爆炸、可燃液体蒸气爆炸、高温熔融物爆炸、管道爆炸）由对应专项预案或现场处置方案承载。

## 应急组织机构及职责

火灾事故应急救援指挥机构与综合预案应急指挥机构为同一机构，直接接受总指挥或副总指挥的统一领导。现场班组长（现场负责人）作为现场最直接、最具体的管理人员，一旦发现直接危及员工人身安全的紧急情况或接到紧急疏散通知后，需立即组织所在班组的员工按规定疏散，并服从公司综合保障组的统一指挥。

## 响应启动

工作时间内第一发现人应立即向部门负责人报告，部门负责人根据事故情况作出是否疏散现场员工的决定，并向总指挥或副总指挥报告；非工作时间内第一发现人立即向现场负责人报告，由现场负责人根据事故地点、种类、强度和可能危害作出疏散决定。报告内容包括：事故发生的时间、地点或岗位及现场情况；已经造成或可能造成的伤亡人数（含下落不明、涉险人数）；已采取的措施。报告方式利用手机、呼叫、手持式扩音器等；紧急情况下可越级报告，或拨打 `{{STREET_OFFICE_NAME}}`"`{{STREET_OFFICE_PHONE}}`"请求支援。公司 24 小时值班电话：`{{COMPANY_24H_PHONE}}`；火警：`{{FIRE_DEPT_NAME}}`"`{{FIRE_DEPT_PHONE}}`"；急救中心：120。发生火灾事故时，应急指挥部必须按法律法规规定将事故情况立即以电话方式向辖区行政部门及应急管理局、公安、医疗等相关部门报告。

## 处置措施

### 灭火基本原则

扑救初起火灾时，必须遵循：先控制后消灭，救人第一，先重点后一般的原则。先控制后消灭是指对于不能立即扑救的火灾，要首先控制火势的继续蔓延和扩大，在具备扑灭条件时再展开全面扑救；救人第一是指火场上如有人受火势围困，应急人员首要任务是把受困人员抢救出来，可视情况救火与救人同时进行；先重点后一般是指对事关全局或生命安全的物资和人员优先抢救。发现起火后火势超出可控范围，应及时拨打 `{{FIRE_DEPT_NAME}}`"`{{FIRE_DEPT_PHONE}}`"报警，讲清着火单位名称、详细地址、着火部位、着火物质、火情大小及报警人姓名电话，并通知门卫到门口等候指引消防车辆。

### 压铸火灾场景专项处置

本企业为压铸加工厂，火灾扑救必须按以下本企业实际火灾场景的专项硬约束执行（与 SP01 火灾事故现场处置方案同源、与 SP21 高温熔融物爆炸事故处置方案认知贯通）：

（1）压铸熔炉、压铸区高温熔融金属（{{slot:melt-types}}）引燃可燃物的火灾：🛑 严禁用水扑救与熔融物直接接触或邻近的可燃物——水流接触熔融物瞬间汽化、体积急剧膨胀，将引发二次蒸气爆炸；应使用干粉灭火剂、干燥沙土覆盖扑救，远离熔融物的可燃物火灾才可常规扑救（贯通 SP21 高温熔融物爆炸事故处置方案，严禁向熔融物注水）。

（2）压铸机液压油火灾：压铸机等高压液压系统的液压油（矿物油）泄漏或受压喷射遇火属 B 类火灾，应立即切断液压泵站动力源，用泡沫、干粉或二氧化碳灭火剂扑救；严禁用直流水柱直接冲击高压油喷射点——高压油雾遇水柱飞溅会扩大燃烧面、加剧立体燃烧。

（3）化学品柜酒精火灾：化学品柜内小量酒精（{{slot:flammable-liquids}}）等水溶性可燃液体火灾，应使用抗溶性泡沫、干粉或二氧化碳灭火剂扑救，并移走柜内邻近可燃物；严禁用直流水冲击流淌的酒精液面——水不能稀释酒精灭火，反而冲散流淌火、扩大火势。

（4）抛光 / 喷砂积尘二次燃爆：抛光、喷砂等工序在设备表面与地面沉积的粉尘，在火灾高温与气流扰动下可被卷扬形成粉尘云发生二次燃爆；扑救时严禁用高压水枪或压缩空气直吹积尘部位，应采用低压雾化水或先湿润再清理，并切断引燃源、隔离产尘区，防止二次爆炸伤人。

### 人员疏散

（1）现场负责人确认发生危及员工人身安全的事故时，应立即向上报告并立即组织员工疏散；综合保障组（警戒疏散小组）用最快速度通知现场无关人员按疏散指示标志、就近原则向集合点有序撤离。

（2）疏散按生产厂房预先制定并张贴于疏散出入口的疏散路线图执行，疏散人员集中地点设于大门口旁空地作为紧急集合点；疏导人员在拐弯、叉道等易走错处提示方向，防止误入死胡同或危险区域。

（3）制止脱险者重返事故现场；救援队伍到场后，疏导人员若知晓内部有人员未疏散出来，要迅速报告被困人员的方位、数量及救人路线，指挥权上移后积极协助疏散抢救。

（4）疏散应先撤事故威胁严重及危险区域内的人员，保持秩序防止拥挤、踩踏、摔倒；疏导人员佩戴防护用品（湿毛巾或防毒面具等），指导逃生人员注意观察安全疏散标志按其指引方向撤离。

## 应急保障

（1）应急救援装备、物资、药品、消防器材、个体防护用品（具）配置齐全，定期检查保养，使其经常处于完好可用状态。

（2）现场配备相应的应急药箱；一旦发生事故，立即将伤员送往就近医院，并及时联系附近抢险救援、消防队、医院进行抢险救护。
