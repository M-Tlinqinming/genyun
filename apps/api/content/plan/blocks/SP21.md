# 高温熔融物爆炸事故现场处置方案

## 事故风险描述

（1）事故类型：高温熔融物爆炸是指处于熔融状态的高温物质（{{slot:melt-types}}）与水或潮湿物体接触，水瞬间汽化（液→气相变体积膨胀约 1700 倍）造成熔融物飞溅与压力冲击的事故；以及熔炉、保温炉、压铸机、浇包等设备因炉衬开裂、冷却系统失效、违规操作导致熔融物外溢、熔体喷溅形成的次生事故。其物理本质是相变能量瞬间释放，根源不是燃烧（不同于可燃气体/液体爆炸 SP19/SP20）、不是容器内压力释放（不同于 SP05）、也不是管道介质轴向喷出（不同于 SP18）——这一独特机制决定了"严禁向熔融物注水"是处置的核心要求。

（2）事故区域：{{slot:furnace-equip}}。本方案涵盖的熔融物为 {{slot:melt-types}}。

（3）事故基本征兆及条件：熔炉炉衬出现裂纹、变色、局部红透或鼓包；冷却水套、冷却循环水管渗漏、压力异常下降；熔炉、浇包、料缸侧壁出现可见漏液或变形；模具、流槽内残留水分或潮湿（铸件未干）；操作工具（钳子、勺、铁锹等）潮湿或带水即接触熔融物；下雨、屋顶漏水使水滴入炉膛或浇包；员工违规将湿冷的金属料、含水物品（含水废料、含水油布、生锈带水的料件）投入炉膛；熔融物运输车辆颠簸导致包内熔融物外溢；炉前操作平台积水或地面渗水未清理。

（4）事故可能造成的危害程度：熔融物飞溅可造成现场人员严重灼烫伤甚至致死（熔融金属温度通常 700–1700℃，瞬间灼烫可深至骨骼）；蒸气爆炸冲击波可摧毁炉膛、震伤人员；飞溅熔融物引燃可燃物造成伴生火灾；炉体破坏可能造成设备报废与厂房结构损伤；熔融物堆积冷却凝固后处理困难，恢复生产周期长。

## 应急工作职责

### 应急组织形式及人员

由现场班组长、熔铸工（持证或经专业培训）和现场员工组成。无现场班组长的，由现场职务最高的员工或对事发区域负有安全责任的员工为现场负责人。

### 主要职责

**现场负责人职责：**

（1）无论在任何时候发生事故，现场负责人首先进入指挥岗位，做好应急处置工作，并安排将情况报告总指挥或副总指挥。

（2）评估事故的严重性及危害程度（熔融物种类、温度、外溢量、影响范围），现场应急力量是否有足够的能力进行处理，决定是否报告总指挥或副总指挥申请应急响应。

（3）下达"严禁注水"指令，制止任何人员凭经验向熔融物注水的行为；下达熔炉断电、燃料切断、人员撤离等关键指令。

（4）如明确事故属于现场处置力量难以控制或人员难以救护性质的，则及早安排将重要物资、人员撤离现场到安全地带，及早拨打"120"请求救护。

**熔铸工职责：**

（1）按熔炉操作规程立即停炉：电炉切断主电源、燃气/燃油炉切断燃料供应；停止鼓风、加料；启动炉体应急冷却保护程序（如设备配置）。

（2）按"严禁向熔融物注水"的要求实施处置：使用干燥沙土、专用熔渣覆盖剂、铸造覆盖砂等无水材料覆盖熔融物，隔离与空气和潜在水源的接触；禁止用水扑救熔融物。

（3）转移熔融物：在条件允许时（炉体未失稳、人员防护到位），将炉内熔融物缓慢转移至应急浇注坑或备用包内，让其自然冷却凝固；转移路径必须事先确认完全无水、无积液。

**现场应急救援人员职责：**听从现场负责人的指挥，进行应急处置及现场急救等工作。

## 应急处置

### 应急处置原则

救人第一的原则——若事故中有人员受到伤害或威胁，首要任务是救人，决不能因其他原因而耽误救人时机。处置高温熔融物爆炸的核心要求是"严禁向熔融物注水"——熔融物温度远超水的沸点，水接触熔融物瞬间汽化、体积膨胀约 1700 倍，必然引发更剧烈的二次蒸气爆炸；这一规则是处置原则中具有"绝对优先级"的红线，先于任何救火、降温、阻隔等本能反应。

### 应急处置程序

发生高温熔融物爆炸或外溢事故，现场人员应立即将事故报告班（组）长，组长报应急总指挥和副总指挥。报警内容应包括：

（1）发生事故的时间；

（2）发生事故的具体位置（熔炉/浇包/压铸机/盐浴炉/转运路径）；

（3）熔融物种类（{{slot:melt-types}}）、估计温度与外溢量；

（4）事故具体类型（熔融物飞溅 / 炉衬破裂外溢 / 蒸气爆炸 / 伴生火灾）；

（5）事故是否已发生人员灼烫伤；

（6）人员受伤或失踪情况；

（7）次生灾害情况（伴生火灾、设备损毁、邻近水源风险等）。

### 现场应急处置措施

（1）人员紧急撤离：现场人员立即从远离熔融物飞溅方向撤离（注意熔融物飞溅可弹跳，撤离不仅要远离喷溅源还要远离反弹路径）；穿戴隔热服、隔热面罩、隔热手套是接近事故区的前提；撤至安全地点后立即汇报班（组）长。

（2）熔炉断能源：电炉立即切断主电源；燃气炉切断燃料供应阀门；停止鼓风、加料、出炉等一切操作——这是与可燃气体爆炸（远程切断气源）和可燃液体蒸气爆炸（控制液源）相区分的具体动作：此处切断的是"为熔融物持续供能"的源头。

（3）🛑 **严禁向熔融物注水（处置高温熔融物爆炸的绝对红线）**：
1）任何形式的水（消防水、自来水、积水、湿润物体）接触熔融物都将瞬间汽化引发二次爆炸；
2）现场负责人必须明确制止任何"用水扑救熔融物"的本能反应；
3）正确的覆盖、阻隔、冷却措施是使用干燥沙土、专用熔渣覆盖剂、铸造覆盖砂、石墨粉、干粉灭火剂等**无水**材料；
4）现场所有水管、水阀、消防栓应在熔融物区域附近暂时关闭，防止误开或破损；
5）下雨或屋顶渗水时立即用防水苫布覆盖事故区，并停止生产撤离人员。

（4）覆盖与隔离：使用干燥沙土或专用覆盖剂将外溢熔融物覆盖，减缓散热与飞溅；以熔融物覆盖区为中心、{{slot:cordon-dist}}划定警戒线；警戒区内禁止无关人员进入，防止熔融物冷却前飞溅伤人。

（5）伴生火灾处置（受熔融物高温引燃可燃物时）：先用干粉灭火剂或沙土扑救受熔融物引燃的可燃物，**严禁用水扑救与熔融物直接接触或邻近的可燃物**——水流可能引导至熔融物处引发二次爆炸；远离熔融物的可燃物火灾按 SP01 火灾事故处置方案处置。

（6）熔融物冷却处置：让熔融物在覆盖剂保护下自然冷却凝固，时间通常需数小时至数十小时；冷却凝固完全前严禁拆除覆盖、严禁人员接近；凝固后由专业人员使用机械或人工方式清理。

### 医疗救护措施

（1）灼烫伤伤员处置（按 SP06 灼烫事故处置方案联动）：迅速脱离热源，穿戴隔热装备的人员将伤员转移至安全区；用大量清水冲洗伤面降温——⚠️ **冲洗对象是已脱离熔融物的伤员皮肤，不是熔融物本身，绝对不可混淆**——冲洗时间不少于 15 分钟；不要揭除粘连衣物以防加重创伤；用洁净敷料覆盖伤面后立即送医；

（2）伴生中毒（金属烟尘、有毒气体）的伤员立即转移至上风开阔处，必要时给氧；

（3）冲击伤、骨折按 SP04/SP11 处置原则处理；

（4）有出血时，应有效止血、包扎伤口；

（5）对失去知觉者，宜清除口鼻中的异物、分泌物、呕吐物，将伤员置于侧卧位以防窒息；

（6）如果伤者出现呼吸或心跳停止，应立即施行人工呼吸和胸外心脏按压，并速送医院。

（1）电话：公司 24 小时值班电话 `{{COMPANY_24H_PHONE}}`；火灾报警 119（熔融物常伴生可燃物火灾，119 同步报警，⚠️ 报警时必须明确告知"高温熔融物事故、消防到场后严禁直接对熔融物射水"）；急救中心 120；三警合一报警 110；辖区消防大队 `{{FIRE_DEPT_NAME}}``{{FIRE_DEPT_DUTY}}`。

（2）应报告以下内容：报警单位名称、发生事故的时间、地点、熔融物种类与估计温度、事故的类型（飞溅 / 炉衬破裂 / 蒸气爆炸 / 伴生火灾）、外溢量与覆盖范围、现场处置和控制情况（重点说明熔融物是否已被无水材料覆盖）、引起的灼烫伤及人员伤亡等内容。

## 注意事项

（1）🛑 **严禁向熔融物注水**——这是处置高温熔融物爆炸的绝对红线，无任何例外。水遇熔融物瞬间汽化、体积膨胀约 1700 倍，将引发剧烈的二次蒸气爆炸，扩大伤亡和损失。任何"用水扑救熔融物"的本能操作都必须被现场负责人立即制止。

（2）严禁使用任何含水或潮湿的工具、物品（湿沙、湿料、含水废料、湿油布、新拌水泥等）接触熔融物；用于覆盖、阻隔、冷却的材料必须事先核实完全干燥。

（3）严禁在熔炉、浇包、模具、流槽等区域积水或放置任何含水物品；下雨、屋顶漏水期间应立即停产并采取防水措施；冷却水套、循环水管出现泄漏迹象时立即停炉检修，不得带病运行。

（4）熔融物的冷却过程必须使其自然降温，不可加速；凝固未完全前严禁拆除覆盖、人员严禁接近——内部仍是熔融状态时，外壳凝固层下的飞溅或塌陷仍可造成严重伤害。

（5）抢险人员必须穿戴完整隔热防护装备（隔热铝箔服、隔热面罩、隔热手套、隔热鞋）进入危险场所；如没有相应隔热装备，不得盲目抢险和救护；伴生火灾按 SP01 联动处置（远离熔融物区域），灼烫伤救护按 SP06 联动。

（6）消防救援单位到场时必须当面再次告知"严禁对熔融物直接射水"，并协同确认水带、水枪不得指向熔融物覆盖区；事故现场应保留至安全监管部门完成调查后再清理。
