# 机械致害事故现场处置方案

## 事故风险描述

（1）事故类型：本企业机械致害风险主要来自 {{slot:danger-machines}} 等生产设备——设备设计缺陷、维修保养不当、故障、违规操作、防护装置损坏等情形下，其运动部位或飞出物与人体接触，导致人体被挤压、剪切、绞伤、飞出物击伤等。

（2）事故区域：{{slot:danger-machines}} 所在的压铸、加工等作业区域。

（3）事故基本征兆及条件：{{slot:danger-machines}} 高速运转、剧烈振动；员工违规操作、劳动保护用品使用不当或缺乏必要的防护用品；以及防护装置损坏、设备维护保养不到位、设备带病运行等。

（4）事故可能造成的危害程度：可能会使人员手指绞伤、皮肤裂伤、断肢、骨折，严重的会使身体被卷入轧伤致死，或者部件、工件飞出，打击致伤或造成死亡。

## 应急工作职责

### 应急组织形式及人员

由现场班组长、机修人员、现场员工组成。无现场班组长的，由现场职务最高的员工或对事发区域负有安全责任的员工为现场负责人。

### 主要职责

**现场负责人职责：**

（1）无论在任何时候发生事故，现场负责人首先进入指挥岗位，做好应急处置工作，并安排将情况报告总指挥或副总指挥。

（2）估计事故的严重性及危害程度，现场应急力量是否有足够的能力进行处理，决定是否报告总指挥或副总指挥申请应急响应。

（3）如能有足够的人力物力处理事故，必须迅速调动相应的人力物力展开应急救援工作。

（4）如明确事故属于现场处置力量难以控制或人员难以救护性质的，则及早拨打"120"请求救护。

**机修人员职责：**机修人员必要时负责停止运行、拆卸设备。

**现场应急救援人员职责：**听从现场负责人的指挥，进行应急处置及现场急救等工作。

## 应急处置

### 事故应急处置

（1）发现有人受伤后，必须立即停止运行的机械，并采取防止机械设备意外启动的防范措施。

（2）将受伤者从机械设备中解脱出来，必要时拆除设备的夹挤、剪切等可能导致二次伤害的零部件。

（3）肢体卷入设备内，必须立即切断电源，并采取防止机械设备意外启动的安全措施，如果肢体仍被卡在设备内，不可用倒转设备的方法取出肢体，妥善的方法是拆除设备部件，无法拆除时拨打 `{{FIRE_DEPT_NAME}}`"`{{FIRE_DEPT_PHONE}}`"请求救援。

（4）将伤者进行简单包扎、止血等措施，防止受伤人员流血过多造成死亡事故发生。创伤出血者迅速包扎止血，送往医院救治。

（5）发生断手、断指等严重情况时，对伤者伤口要进行包扎止血、止痛、进行半握拳状的功能固定。对断手、断指应用消毒或清洁敷料包好，忌将断指浸入酒精等消毒液中，以防细胞变质。将包好的断手、断指放在无泄漏的塑料袋内，扎紧好袋口，在袋周围放置冰块，速随伤者送医院抢救。

（6）发生头皮撕裂伤可采取以下急救措施：及时对伤者进行抢救，采取止痛及其他对症措施；用生理盐水冲洗有伤部位，用消毒大纱布块、消毒棉花紧紧包扎，压迫止血；送医院进一步治疗。

（7）受伤人员出现肢体骨折时，应尽量保持受伤的体位，对伤肢进行固定，并采用正确的方式进行抬运，防止因救助方法不当导致伤情进一步加重。

（8）受伤人员出现呼吸、心跳停止症状的，必须立即进行胸外按压或人工呼吸。

### 报警电话及报警内容

（1）电话：公司 24 小时值班电话 `{{COMPANY_24H_PHONE}}`；火灾报警 119；三警合一报警 110；急救中心 120。

（2）应报告以下内容：报警单位名称、发生事故的时间、地点、事故的类型、发展和蔓延情况、现场处置和控制情况、引起的机械故障及人员伤亡等内容。

## 注意事项

（1）使用的抢险救援器材、设备应完好。

（2）在发生事故后应根据现场情况，在保证自身安全的前提下，采取积极有效的方法进行救援。

（3）在组织抢险救援过程中，要密切注意灾情变化，当可能出现危及人员安全时，要果断采取有效措施，避免人员伤亡。
