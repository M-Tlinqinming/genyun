# 粉尘爆炸事故专项应急预案

## 适用范围

本专项应急预案适用于公司喷砂、抛光、CNC 加工等产尘作业场所（{{slot:dust-workstations}}）发生铝、锌等可燃金属粉尘爆炸事故的应急处置；适用于事故初始阶段，或现场班组应急力量无法有效处置的较大事故的应急处置。本企业为铝、锌压铸件机械加工厂，喷砂、抛光、CNC 等工序对铝、锌压铸件表面去除产生铝、锌等可燃金属粉尘，当粉尘清扫不及时、除尘系统不畅、粉尘浓度超过爆炸极限并遇火花、高温、静电或铝粉与水反应放热时，即可能发生粉尘爆炸事故。

粉尘爆炸的连锁后果包括：

（1）粉尘爆炸是可燃性粉尘在空气中浮游，当一种火源给予一定的能量后发生的爆炸；

（2）粉尘爆炸有产生二次爆炸的可能性。由于粉尘的初始爆炸气浪会将沉积粉尘扬起，在新的空间达到爆炸浓度而产生二次爆炸。这种连续爆炸会造成极大的破坏，严重的可危及到周边建筑和群众，造成重大伤亡；

（3）铝、锌等可燃金属粉尘遇水、受潮发生放热反应并产生氢气，遇高温火花可发生剧烈燃爆，扑救方式与有机粉尘根本不同（详见处置措施金属粉尘场景专项处置）。

## 应急组织机构及职责

粉尘爆炸事故应急救援指挥机构与综合预案应急指挥机构为同一机构，直接接受总指挥或副总指挥的统一领导。但现场班组长（现场负责人）作为现场最直接、最具体的管理人员，一旦发现直接危及员工人身安全的紧急情况或接到紧急疏散通知后，需立即组织所在班组的员工按规定疏散，并服从公司综合保障组的统一指挥。

粉尘爆炸场景下，各应急小组职责特化如下：

（1）抢险救灾组：负责立即停机、切断现场电源开关、组织扑救火灾，开展现场断电、通风等控制措施，按金属粉尘火灾专用方式处置；

（2）警戒疏散组：负责事故现场及邻近区域的隔离区管控，防止人员重返现场，重点防范二次粉尘爆炸；

（3）通讯联络组：负责事故信息上报、外部救援单位联络，向消防救援队伍准确说明属铝、锌可燃金属粉尘火灾、严禁直流水扑救；

（4）医疗救护组：负责伤员的现场急救与转运，重点关注烧伤、爆炸冲击伤与吸入性损伤。

## 响应启动

工作时间内第一发现人发现事故后，应立即向部门负责人报告，部门负责人应根据事故情况作出是否疏散现场员工的决定，并向总指挥或副总指挥报告；非工作时间内第一发现人立即向现场负责人报告，由现场负责人根据事故地点、种类、强度和可能危害作出疏散决定。报告内容包括：事故发生的时间、地点或岗位及现场情况；已经造成或可能造成的伤亡人数（含下落不明、涉险人数）；已采取的措施。报告方式利用手机、呼叫等；紧急情况下可越级报告，拨打 `{{FIRE_DEPT_NAME}}`"`{{FIRE_DEPT_PHONE}}`"请求支援。公司 24 小时值班电话：`{{COMPANY_24H_PHONE}}`；火警：`{{FIRE_DEPT_NAME}}`"`{{FIRE_DEPT_PHONE}}`"；急救中心：120。

## 处置措施

### 初期处置

发现灾情，现场作业人员立即停机、切断现场所有电源开关、通知现场及附近人员紧急撤离，并迅速向应急指挥部报告；力争在事故初期得到控制。当现场人员不能及时扑救、需启动公司应急预案时，公司应急指挥部接到报告后立即组织力量展开抢险扑救，成立现场指挥中心，指挥各应急小组展开应急救援工作。

### 金属粉尘场景专项处置

本企业为铝、锌压铸件机械加工厂，喷砂、抛光、CNC 等工序（{{slot:dust-workstations}}）产生铝、锌（{{slot:metal-dust-types}}）等可燃金属粉尘，粉尘爆炸处置必须按以下本企业实际金属粉尘场景的专项硬约束执行（P2 粉尘爆炸事故专项应急预案与 SP10 粉尘爆炸事故现场处置方案同源、命门逐字一致）：

（1）🛑 严禁用水、泡沫或常规灭火剂扑救铝、锌等可燃金属粉尘火灾——铝、镁金属粉尘遇水在高温下发生剧烈放热反应并产生氢气，会加剧燃烧、引发爆炸；金属粉尘火灾属 D 类金属火灾，须改用专用方式处置（依据 AQ 4272-2016《铝镁制品机械加工粉尘防爆安全技术规范》7.2 与 5.2、GB/T 4968 火灾分类 D 类金属火灾）。

（2）🛑 铝、锌等金属粉尘严禁与水、铁锈或其它化学物质接触或受潮——接触或受潮会发生放热反应、生成氢气并可能自燃；沉积的金属粉尘严禁直接喷水冲洗，湿式除尘与积尘清理须按“产生氢气的危险区”控制氢气浓度低于爆炸下限，收集的粉尘须装入非铝质金属或防静电容器并隔离存放、作无害化处置（依据 AQ 4272-2016 5.2、10.4 与 12.3）。

（3）🛑 扑救铝、锌等金属粉尘火灾应使用 D 类（金属火灾专用）灭火器材或干燥沙土、专用覆盖剂，以覆盖、隔绝空气方式窒息灭火，严禁使用普通水基、泡沫、ABC 干粉及二氧化碳灭火器材直接喷射粉尘层（依据 AQ 4272-2016 7.2 粉尘爆炸环境危险区域应采用 D 类或冷金属灭火器材、覆盖剂进行灭火）。

（4）严禁使用压缩空气清扫现场粉尘，防止扬尘引发二次爆炸；清理金属粉尘应采用不产生扬尘的清扫方式与不产生火花的清扫工具，宜采用负压吸尘（依据 AQ 4272-2016 12.2、12.3，模板原文保留）。

（5）粉尘的初始爆炸气浪会将沉积粉尘扬起，在新空间达到爆炸浓度而产生二次爆炸，连续爆炸破坏极大；事故隔离区内严禁任何明火及非防爆电气作业，除应急救援人员外其他人员一律撤出隔离区外（模板原文二次爆炸机理与隔离区管控保留）。

### 二次爆炸防范

保安值班人员接到事故预警信号后，立即开启厂区大门，必要时派人到相关路口带引消防车，并担负厂区治安和交通指挥，在事故现场周围设岗，划分禁区并加强警戒和巡逻检查。隔离区内严禁任何明火及非防爆电气作业；除应急救援人员外，其他人员一律撤出隔离区外。如事故扩大危及到周围人员安全时，应迅速组织有关人员协助友邻单位、过往行人在政府指挥中心指挥协调下，向上侧风方向的安全地带疏散。

### 伤员救护

当现场有人受伤时，应立即救护伤员，对烧伤、爆炸冲击伤、吸入性损伤者及时采取相应急救措施，对伤员进行清洗包扎等急救处置，重伤员及时送往附近医院抢救。并根据指挥中心命令，及时组织事故抢险所需物资的供应、调运，对内外联系、准确报警，进行现场与外界有效沟通以获得社会支援。

## 应急保障

（1）应急救援装备、物资、药品、消防器材、个体防护用品（具）均配置齐全，并规定定期检查保养，使其经常处于完好可用状态；粉尘爆炸环境危险区域应按 AQ 4272-2016 7.2 配置 D 类（金属火灾专用）灭火器材、专用覆盖剂及干燥沙土，不得以普通水基/泡沫/ABC 干粉灭火器材替代。

（2）防爆装置维护：生产设备、通风管道采取防静电措施；使用防爆电气设备；泄爆、阻爆、隔爆装置定期检查保养。

（3）除尘系统维护：所有产尘点装设吸尘罩；每周至少一次对通风系统进行除尘清扫；所有可能积累粉尘的生产车间和贮存室的设备、地面每天至少清扫一次，采用不产生扬尘的清扫方式，不得使用压缩空气进行吹扫。

（4）配置应急车辆，一旦发生事故立即将伤员送往就近医院；及时联系附近抢险救援、消防队、医院进行抢险救护。
