# 粉尘爆炸事故现场处置方案

## 事故风险描述

（1）事故类型：本企业为铝、锌压铸件机械加工厂，喷砂、抛光、CNC 加工等工序对铝、锌压铸件表面去除会产生大量铝、锌等可燃金属粉尘；当粉尘清扫不及时、除尘系统不畅、粉尘浓度达到爆炸极限，遇火花、高温、静电火花，或铝、锌粉尘与水、铁锈接触放热反应时，可能引起粉尘燃爆，造成火灾、人员伤残、死亡，以及引发其他安全生产事故。

（2）事故区域：喷砂工序、抛光工序、CNC 加工工序等产尘点（{{slot:dust-workstations}}）、除尘系统及积尘部位。

（3）事故基本征兆及条件：粉尘清扫不及时、通风除尘系统不畅、粉尘浓度超过爆炸极限，遇违规焊割、打磨明火、静电火花、烟头，或铝、锌金属粉尘遇水/受潮放热产氢即可能发生粉尘爆炸事故。

（4）事故可能造成的危害程度：粉尘爆炸可能造成火灾爆炸、烧伤、爆炸冲击伤、人员伤残、死亡，以及引发其他安全生产事故。

## 应急工作职责

### 应急组织形式及人员

由现场班组长和现场员工组成。无现场班组长的，由现场职务最高的员工或对事发区域负有安全责任的员工为现场负责人。

### 主要职责

**现场负责人职责：**

（1）无论在任何时候发生事故，现场负责人首先进入指挥岗位，做好应急处置工作，并将情况报告总指挥或副总指挥。

（2）估算事故的严重性及危害程度，现场应急力量是否有足够的能力进行处理，决定是否报告总指挥或副总指挥申请外部救援力量支援。

（3）如能有足够的人力物力处理事故，必须迅速调动相应的人力物力展开应急救援工作，按金属粉尘火灾专用方式处置。

（4）如明确事故属于现场处置力量难以控制或人员难以救护性质的，则及早安排将重要物资、人员撤离现场安全地带，情况危急时拨打 `{{FIRE_DEPT_NAME}}`"`{{FIRE_DEPT_PHONE}}`"、120、110 请求支援。

**现场应急救援人员职责：** 听从现场负责人的指挥，进行应急处置及现场急救等工作。

## 应急处置

### 事故应急处置

（1）现场作业人员发生粉尘爆炸事故后，立即停机、断电、通风，最大限度降低粉尘浓度。

（2）通知现场及附近人员紧急撤离事故现场，并立即向现场负责人或上级报告。

（3）当事故超出企业自救能力时，及时拨打 110 报警电话和 120 急救电话。

（4）撤离爆炸现场附近的可燃物，避免爆炸引起火灾区域扩大。

### 飞宇金属粉尘场景专项处置

本企业为铝、锌压铸件机械加工厂，喷砂、抛光、CNC 等工序（{{slot:dust-workstations}}）产生铝、锌（{{slot:metal-dust-types}}）等可燃金属粉尘，粉尘爆炸处置必须按以下飞宇实际金属粉尘场景的专项硬约束执行（SP10 粉尘爆炸事故现场处置方案与 P2 粉尘爆炸事故专项应急预案同源、命门逐字一致）：

（1）🛑 严禁用水、泡沫或常规灭火剂扑救铝、锌等可燃金属粉尘火灾——铝、镁金属粉尘遇水在高温下发生剧烈放热反应并产生氢气，会加剧燃烧、引发爆炸；金属粉尘火灾属 D 类金属火灾，须改用专用方式处置（依据 AQ 4272-2016《铝镁制品机械加工粉尘防爆安全技术规范》7.2 与 5.2、GB/T 4968 火灾分类 D 类金属火灾）。

（2）🛑 铝、锌等金属粉尘严禁与水、铁锈或其它化学物质接触或受潮——接触或受潮会发生放热反应、生成氢气并可能自燃；沉积的金属粉尘严禁直接喷水冲洗，湿式除尘与积尘清理须按“产生氢气的危险区”控制氢气浓度低于爆炸下限，收集的粉尘须装入非铝质金属或防静电容器并隔离存放、作无害化处置（依据 AQ 4272-2016 5.2、10.4 与 12.3）。

（3）🛑 扑救铝、锌等金属粉尘火灾应使用 D 类（金属火灾专用）灭火器材或干燥沙土、专用覆盖剂，以覆盖、隔绝空气方式窒息灭火，严禁使用普通水基、泡沫、ABC 干粉及二氧化碳灭火器材直接喷射粉尘层（依据 AQ 4272-2016 7.2 粉尘爆炸环境危险区域应采用 D 类或冷金属灭火器材、覆盖剂进行灭火）。

（4）严禁使用压缩空气清扫现场粉尘，防止扬尘引发二次爆炸；清理金属粉尘应采用不产生扬尘的清扫方式与不产生火花的清扫工具，宜采用负压吸尘（依据 AQ 4272-2016 12.2、12.3，模板原文保留）。

（5）粉尘的初始爆炸气浪会将沉积粉尘扬起，在新空间达到爆炸浓度而产生二次爆炸，连续爆炸破坏极大；事故隔离区内严禁任何明火及非防爆电气作业，除应急救援人员外其他人员一律撤出隔离区外（模板原文二次爆炸机理与隔离区管控保留）。

### 伤员救护

（1）迅速将伤者移到安全地方，让伤者安静、保暖、平卧、少动，并将下肢抬高约 20 度左右。

（2）使昏迷者平卧，面部转向一侧，以防舌根下坠或分泌物、呕吐物吸入，发生咽喉阻塞。

（3）发现伤者手足骨折或其他部位骨折的，不要盲目搬动伤者，应在骨折部位用夹板临时固定，使断端不再移位或刺伤肌肉、神经或血管；固定办法以固定骨折处上下关节为原则，可以就地取材，用木板、竹片等，在无材料的情况下，上肢可固定在身侧，下肢与健侧下肢缚在一起。

（4）遇有创伤性出血的伤员，应迅速包扎止血，使伤员保持在头低脚高的卧位，并注意保暖。

（5）在施救的同时应尽快送往就近医院；伤者送往医院抢救时，途中尽量减少颠簸，同时密切注意伤者的呼吸、脉搏、血压及伤口的情况。

（1）电话：公司 24 小时值班电话 `{{COMPANY_24H_PHONE}}`；辖区消防大队 `{{FIRE_DEPT_NAME}}` `{{FIRE_DEPT_PHONE}}`；三警合一报警 110；急救中心 120。

（2）应报告以下内容：报警单位名称、发生事故的时间、地点、事故的类型、发展和蔓延情况、现场处置和控制情况、引起伤害及人员伤亡等内容，并准确说明属铝、锌可燃金属粉尘火灾、严禁直流水扑救。

## 注意事项

（1）抢险人员必须佩戴好个人防护用品（防静电工装、防尘口罩等）进入危险场所进行抢险和救护。

（2）实施抢险救援时应先救人再实施其他抢险。

（3）现场救护与抢险相结合，如没有相应个人防护用品，不得盲目抢险和救护。

（4）扑救金属粉尘火灾严禁用水、泡沫及普通灭火器材直接喷射，应按飞宇金属粉尘场景专项处置执行。

（5）设立警戒区防止无关人员进入危险区。

（6）严禁使用压缩空气清扫粉尘，防止扬尘引发二次爆炸。
