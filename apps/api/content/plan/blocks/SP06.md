# 灼烫事故现场处置方案

## 事故风险描述

（1）事故类型：生产过程中需使用到 `{{REPRESENTATIVE_CHEMICALS}}` 等化学品，员工若操作不当不慎接触皮肤、眼睛，可能发生化学品灼伤事故；高温设备、维修焊接等作业过程中可能发生物理灼烫事故。**涉及熔融金属浇铸 / 压铸作业的，高温熔融金属（{{slot:melt-types}}）接触或飞溅是本企业的签名灼烫源——熔融金属温度数百摄氏度，瞬间灼烫可深至骨骼，与一般烫伤的处置存在根本差异（见下「熔融金属接触 / 飞溅灼烫专项救护」），并与 SP21 高温熔融物爆炸事故处置方案联动。**

（2）事故区域：生产车间；涉及熔融金属作业的，含熔炉 / 压铸机 / 浇包 / 转运路径等高温作业区。

（3）事故基本征兆及条件：员工未按规定穿防护服、配戴劳动防护用品；现场警示标识不足；安全间距不足；作业环境不良；使用化学品操作失当；熔融金属作业未穿戴隔热防护、料缸 / 模具 / 浇包带水或潮湿、违规跨越熔融金属转运路径。操作人员操作失误、违反操作规程、离岗等。

（4）事故可能造成的危害程度：对人体可能产生烫伤、化学灼伤，严重的可导致伤残；高温熔融金属接触 / 飞溅可造成大面积深度灼烫甚至致死。

## 应急工作职责

### 应急组织形式及人员

由现场班组长和现场员工组成。无现场班组长的，由现场职务最高的员工或对事发区域负有安全责任的员工为现场负责人。

### 主要职责

**现场负责人职责：**

（1）无论在任何时候发生事故，现场负责人首先进入指挥岗位，做好应急处置工作，并安排将情况报告总指挥或副总指挥。

（2）估算事故的严重性及危害程度，现场应急力量是否有足够的能力进行处理，决定是否报告总指挥或副总指挥申请应急响应。

（3）如能有足够的人力物力处理事故，必须迅速调动相应的人力物力展开应急救援工作。

（4）如明确事故属于现场处置力量难以控制或人员难以救护性质的，则及早安排将重要物资、人员撤离现场到安全地带。

**现场应急救援人员职责：** 听从现场负责人的指挥，进行应急处置及现场急救等工作。

## 应急处置

### 熔融金属接触 / 飞溅灼烫专项救护（涉及熔融金属浇铸 / 压铸作业时执行；本企业不涉及熔融金属作业时本节略）

涉及熔融金属（{{slot:melt-types}}）作业时，发生熔融金属接触 / 飞溅灼烫，除一般烧烫伤救护外，必须特别执行以下专项措施（与 SP21 高温熔融物爆炸事故处置方案同源、认知贯通）：

（1）迅速脱离热源，穿戴隔热装备的人员将伤员转移至安全区；用大量清水冲洗伤面降温——⚠️ **冲洗对象是已脱离熔融物的伤员皮肤，不是熔融物本身，绝对不可混淆**——冲洗时间不少于 15 分钟；不要揭除粘连衣物以防加重创伤；用洁净敷料覆盖伤面后立即送医。

（2）🛑 贯通 SP21 绝对红线「严禁向熔融物注水」：对仍附着于伤者体表、尚未凝固脱离的熔融金属或熔渣，严禁向其浇水降温——水接触熔融物瞬间汽化、体积急剧膨胀，将加重灼伤并引发二次伤害；让其在隔离保护下自然冷却，由专业人员处理，严禁强行撕揭粘连创面的熔融金属或熔渣。

（3）大面积、深度灼伤或熔融金属灼烫：让伤者平卧、保暖、防休克，以洁净敷料覆盖创面，**禁用任何偏方涂抹（白糖、牙膏、酱油、酱料等一律不可）**，立即拨打 120 并专业转运送医，途中持续监护呼吸、意识。

### 物理烫伤（一般）

（1）对 1 度烧烫伤和浅 2 度烧烫伤，可立即用冷水浸泡 15～20 分钟；

（2）深 2 度及以上、大面积烧烫伤或熔融金属灼烫，**不得使用任何偏方涂抹（如白糖浓糖水、牙膏等，均为错误有害处置）**；应迅速使被烫伤者脱离热源、平卧以减少休克，用较清洁的衣服、被单等迅速覆盖伤面避免再次污染，按上述「熔融金属接触 / 飞溅灼烫专项救护」处置并尽快就医；

（3）发生烧烫伤后，对着火或被烫伤者，迅速解脱或剪除衣服时遵守「沾着不易剪除的衣服不要强求脱掉」（见注意事项），避免弄破水泡皮，应尽快就医。

### 化学性皮肤烧伤

发生化学性皮肤烧伤时，应立即将患者移离现场，迅速脱去被化学物沾污的衣裤、鞋袜等，**用足量流动清水持续冲洗创面 15 min 以上（以大量流动清水持续冲洗为首要、规范处置）**。若无冲洗条件，可细心擦净水份，将患部用干净的布盖住。新鲜创面上不要任意涂油膏或红药水、紫药水等，应尽快就医。

### 化学性眼烧伤

发生化学性眼烧伤时，应立即用流动清水冲洗，以免造成失明。冲洗被烧伤的眼睛要在下方，防止冲洗过的水流进另一只眼睛。无法冲洗时，也可把脸部埋入清洁水中。清洗过程中要定时把眼皮掰开，眼球来回转动洗涤 20 min 以上。

（如涉及电石、生石灰等遇水放热 / 反应性化学品颗粒溅入眼内——本企业不涉及此类化学品时本项略：应先用蘸石蜡油或植物油的棉签去除颗粒，再用水冲洗。）不论哪一种眼烧伤，充分冲洗后都要立即到医院眼科治疗。

### 火焰烧伤

发生火焰烧伤时，应立即脱去着火的衣服，并迅速卧倒，慢慢滚动而压灭火焰，切忌用双手扑打，以免双手重度烧伤；切忌奔跑，以免发生呼吸道烧伤。

对中小面积的四肢创面可用清洁的冷水（一般在 10～20℃，夏季 3～5℃）冲洗 30 min 以上，然后简单包扎，去医院进一步处理。

### 报警电话及报警内容

（1）电话：公司 24 小时值班电话 `{{COMPANY_24H_PHONE}}`；三警合一报警 110；急救中心 120。

（2）应报告以下内容：报警单位名称、发生事故的时间、地点、事故的类型、发展和蔓延情况、现场处置和控制情况、引起的灼烫及人员伤亡等内容。

## 注意事项

（1）对沾着不易剪除的衣服不要强求脱掉，尽量不要弄破水泡皮；粘连于创面的熔融金属 / 熔渣同理，严禁强行撕揭，待专业处理。

（2）创面不要涂物或油脂，附着异物也暂时不要去掉，待送医院后处理；

（3）妥善保护创面，避免再次污染，不可用碘酒、酒精、红汞等消毒药物涂擦创面，以免加重损伤或影响下一步观察治疗。
