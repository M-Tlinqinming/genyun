# 火灾爆炸事故专项应急预案

## 适用范围

本专项应急预案适用于公司的火灾爆炸事故的应急处置，适用于上述事故初始阶段，或现场班组应急力量无法有效处置的较大事故的应急处置。

## 应急组织机构及职责

火灾爆炸事故人员疏散应急救援指挥机构与综合预案应急指挥机构为同一机构，直接接受总指挥或副总指挥的统一领导。但现场班组长（现场负责人）作为现场最直接、最具体的管理人员，一旦发现直接危及员工人身安全的紧急情况或接到紧急疏散通知后，需立即组织所在班组的员工按规定疏散，并服从公司综合保障组的统一指挥。

## 响应启动

### 信息报告程序

工作时间内发现事故后，第一发现人应立即向部门负责人报告，部门负责人应根据事故情况作出是否疏散现场员工的决定，并向总指挥或副总指挥报告。

非工作时间内发生事故，第一发现人应立即向现场负责人报告，现场负责人接到报告后，根据事故发生地点、种类、强度和事故可能的危害作出是否疏散员工的决定。

### 信息报告内容

①事故发生的时间、地点或岗位及事故现场情况；

②事故已经造成或可能造成的伤亡人数（包括下落不明、涉险的人数）；

③已经采取的措施。

### 信息报告方式

主要利用手机、呼叫、手持式扩音器等方式进行报告。事故现场负责人和应急指挥部按预警级别逐级上报，紧急情况下，可越级报告，`{{STREET_OFFICE_NAME}}`“`{{STREET_OFFICE_PHONE}}`”请求支援。

当发生火灾爆炸事故时，应急指挥部必须按照法律、法规和标准的规定将事故有关情况立即以电话方式向辖区内行政部门及应急管理局（应急救援指挥中心）、公安、医疗等相关部门报告，向可能受影响的居民通报。

## 处置措施

### 火灾爆炸处置

**1）一般火灾处置措施**

（1）如发现起火后，火势超出可控范围，都应及时`{{FIRE_DEPT_NAME}}`“`{{FIRE_DEPT_PHONE}}`”电话报警。设有手动报警设施的，应击碎其保护层的玻璃报警。报警时要讲清着火单位名称、详细地址、着火部位、着火物质、火情大小及报警人姓名和报警电话。报警后要通知门卫到门口等候，指引消防车辆。发生火灾时，在场人员在立即扑救、报警的同时，还应迅速通知办公室人员或公司消防管理人员。

（2）值班人员接到火灾报警或收到自动报警信号后，应迅速通过{{CHECK_MEANS}}了解起火点，证实后立即启动灭火装置或利用附近的火灾防范设备、器材灭火，同时`{{FIRE_DEPT_NAME}}`“`{{FIRE_DEPT_PHONE}}`”电话报告火警，而后通过{{ALARM_MEANS}}，依照烟、火蔓延扩散威胁的严重程度区分人员不同的区域层次，逐楼层、逐区域地通知，并沉着、镇静地指明疏散路线和方向。同时应急救援组立即赶往起火地点，安排人员进行扑救和人员疏散工作。

（3）扑救初起火灾时，必须遵循：先控制后消灭，救人第一，先重点后一般的原则。先控制后消灭是指对于不能立即扑救的火灾，要首先控制火势的继续蔓延和扩大，在具备扑灭火灾的条件时，再展开全面的扑救。救人第一是指火场上如果有人受到火势的围困时，应急人员首要的任务就是把受困的人员从火场中抢救出来。在运用这一原则时可视情况，救火与救人同时进行，以救火保证救人的展开，通过灭火，从而更好地救人脱险。先重点后一般是指在扑救初起火灾时，要全面了解并认真分析火场情况，区别重点与一般，对事关全局或生命安全的物资和人员要优先抢救，之后再抢救一般物资。

（1）发现火情，现场工作人员立即采取措施处理，防止火势蔓延并迅速报告。初起火灾，着火面积较小，由起火现场的操作人员应从源头上消灭火灾（如切断泄漏源、移走易燃物品等），正确使用消防器材（干粉灭火器、砂土等），按正确的灭火方法灭火，力争在火灾初期得到控制、扑灭火灾，力求最小的事故损失。

（2）当现场人员不能及时扑救，启动了公司应急预案时，公司应急救援指挥部接到报告后，立即组织力量展开着火区域火灾扑救。同时成立现场指挥部，指挥各应急小组展开应急救援工作。

（3）抢险、抢修人员到达现场后，佩戴好防毒面具，立即启动消防水泵，驳接好消防水带，扑救火灾，同时用消防水冷却和保护未燃烧区，隔离现场，切断电源、火源，防止事故扩大、蔓延。扑救火灾时，若有作业人员困于火场之中，要优先救人，即“先救人，后救物”；用水压制火势，开辟出一条逃生通道。

若火灾快速蔓延，可能影响周边建筑物时，应对可能被影响的建筑物喷水进行冷却。

当消防救援队到来后，将事故情况向消防救援队说明清楚。应急队员服从消防救援队的指挥。如事故扩大有危及生命危险时，参与应急的队员应尽快撤离到安全地方。

（4）保安值班人员接到事故预警信号后，立即开启厂区大门，必要时派人到相关路口带引消防车。

（5）综合保障组（警戒疏散小组）到达现场后，担负治安和交通指挥，在事故现场周围设岗，划分禁区并加强警戒和巡逻检查。

如当事故扩大危及到周围人员安全时，应迅速组织本单位人员、友邻单位、过往行人在政府指挥部指挥协调下，向上侧风方向的安全地带疏散。

（6）综合保障组救护人员到达现场后，当现场有人受伤或中毒时，与消防队配合，应立即救护伤员和中毒人员，对中毒人员应根据中毒症状及时采取相应的急救措施，对伤员进行清洗包扎等急救处置，重伤员及时送往附近医院抢救。

（7）通讯联络组到达现场后，根据指挥部的命令，及时组织事故抢险过程中所需物资的供应、调运；对内、外联系，准确报警，及时向社会救援组织传递安全信息，发布险情，进行现场与外界有效沟通，以获得有力的社会支援。

**3）锂电池火灾处置措施**

（1）识别征兆：锂电池出现鼓胀变形、外壳发烫、冒白烟或有刺激性气味、发出嘶嘶声或爆裂声时，即可能已发生热失控，发现人应立即报告现场负责人并按本节处置。

（2）隔离：在确保自身安全的前提下，立即切断相关充放电、检测设备电源；尚未起火的单只冒烟电池，可用火钳等绝缘工具移至室外空旷处或投入盛水容器浸泡，严禁徒手接触；成箱、成组或已起火的电池不得搬动，迅速转移周边未受影响的电池和可燃物，划定隔离区，无关人员撤离。

（3）灭火与冷却：初起明火可用干粉、二氧化碳灭火器扑灭，随即用大量水（或水基型灭火器、锂电池专用灭火剂）对电池持续冷却，直至电池不再冒烟、温度降至常温；干粉、二氧化碳只能压制明火，不能阻止热失控向相邻电池蔓延，不得以明火熄灭作为处置结束。

（4）防护：处置人员应站在上风向，佩戴空气呼吸器等呼吸防护用品，不得正面抵近起火电池，防止电池爆燃、喷射伤人；热失控烟气含一氧化碳、氟化氢等有毒成分，烟气较大的室内严禁无呼吸防护进入。

（5）复燃监护：明火扑灭、冷却后应设专人持续监护，确认电池温度稳定、不再冒烟后方可撤除；受损电池单独隔离存放（室外隔离区或浸水容器），不得放回仓库或与完好电池混放，交有资质的单位处置。

（6）火势无法控制时立即拨打火灾报警 119，并告知消防救援人员起火物为锂电池及大致数量、存放位置。

### 火灾爆炸事故人员疏散措施

**1）一般场所疏散方案**

（1）现场负责人或其他人员确认发生危及员工人身安全的事故时，应立即向上报告，现场负责人在发现直接危及员工人身安全的紧急情况时，应立即组织员工疏散。

各楼层最高职务管理人员或安全员为此层疏导指挥，各区域楼层靠近疏散出口的员工，为疏散引导员。

（2）综合保障组（警戒疏散小组）用最快的速度通知现场无关人员按疏散的方向和通道进行疏散。

（3）当有抢险救灾组或关部门（如消防队）到达事故现场后，现场负责人和工作人员主动汇报事故现场情况，指挥权上移后，积极协助做好疏散抢救工作。

**2）正确通报、防止混乱**

现场负责人或疏散组在接报后，应首先通知事故区域及附近的人员，将他们先疏散出去，然后视情况公开通报，告诉其他部位（区域）人员进行有序疏散。

按照生命安全第一，财产安全第二的原则，所有人员听到火警时应该迅速按平时演练方案进行疏散撤离。人员疏散路线按就近原则从楼梯往下撤离，不准乘坐电梯。

**3）疏散处置程序**

（1）口头引导疏散

疏导人员到紧急集合点，要用镇定的语气呼喊，劝说人们消除恐惧心理、稳定情绪，使大家能够积极配合，按各区域楼层应急指定路线有条不紊地进行疏散。

（2）强行疏导、疏散

如果事故现场，直接威胁人员安全，现场负责人应采取必要的手段强制疏导，防止出现伤亡事故。在疏散通道的拐弯叉道等容易走错方向的地方，各区域负责人应设相关疏导人员，提示疏散方向，防止误入死胡同或进入危险区域。

（3）制止脱险者重返事故现场

对疏散出来的人员，要加强脱险后的管理，防止脱险人员对财产和未撤离危险区的员工生命担心而重新返回事故现场，必要时，在进入危险区域的关键部位配备警戒人员。

**4）被困人员的疏散**

事故现场有受到火警威胁的被困人员时，综合保障组紧急疏散小组应引导受困人员听从指挥，做到有组织、有秩序地进行疏散；各区域负责人要安排核实本区的洗手间或较为密闭的场所进行喊话检查，确保全部人员安全疏散到紧急集合点。

有关救援队伍到达事故现场后，疏导人员若知晓内部有人员未疏散出来，要迅速报告。介绍被困人员的方位、数量以及救人的路线。

**6）疏散人员应注意事项**

（1）保持安全疏导秩序，防止出现拥挤、踩踏、摔倒的事故发生；

（2）应遵循的疏导顺序；

（3）疏散应先事故地点人员的顺序进行，以疏散到安全地点为主要目标；

（4）先安排事故威胁严重及危险区域内的人员疏散；

（5）发扬团结友爱，尽力救助更多的人员撤离事故现场；

（6）疏散、控制事故现场，控制火势和火场排烟，为安全疏散创造有利条件；

（7）逃生中注意自我保护，学会逃生基本方法，疏导人员应指导逃生疏散人员，正确运用逃生方法，尽快撤离事故现场；

（8）注意观察安全疏散标志，按其指引方向，尽快引导人员撤离事故现场；

在既被火封锁，救援人员又未能到位的危急情况下，楼层低的可用绳索或将窗帘接成条，系住一端沿布条攀沿逃生，切忌擅自从高楼往下跳。

（9）疏导人员应佩戴所需的防护用品（使用湿毛巾或防毒面具等）。

## 应急保障

（1）应急救援装备、物资、药品、消防器材、个体防护用品（具）应配置齐全，并定期检查保养，使其经常处于完好可用状态。

（2）现场应配备相应的应急药箱，提供应急所需。一旦发生事故，立即将伤员送往就近的医院。

（3）及时联系附近抢险救援、消防队、医院，进行抢险救护。
