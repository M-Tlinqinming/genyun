# 有限空间专项应急预案

## 适用范围

该有限空间专项事故应急预案适用于企业中使用的废气环保设施、污水池，如空气中的氧气浓度低于18%或者存在其它有毒有害气体时，检查、维修、清理污水池时操作人员违规作业，未按规定审批作业、佩戴防护用品可能造成中毒、缺氧窒息事故抢救不及时可致人死亡。

## 应急组织机构及职责

应急救援指挥机构与综合预案应急指挥机构为同一机构，直接接受总指挥或副总指挥的统一领导。但现场班组长（现场负责人）作为现场最直接、最具体的管理人员，一旦发现直接危及员工人身安全的紧急情况或接到紧急疏散通知后，需立即组织所在车间的员工按规定疏散，并服从公司联络疏散组和医疗后勤组的统一指挥。

（1）总指挥部职责

1）负责启动和终止本企业应急救援预案；

2）负责组织指挥本企业应急小组现场救援工作；

3）负责本企业应急救援行动中物资及人员调配；

4）负责第一时间或指定他人如实向上级主管部门报告事故情况；

5）副总指挥负责协助总指挥做好现场抢险救灾工作的紧急组织，向总指挥汇报情况，落实总指挥发布的抢险命令，当总指挥不在公司时，自动承担总指挥职责。

（2）现场抢修组职责

1）负责事故现场受伤人员的抢救和失踪人员的搜救工作；

2）采用合适手段，迅速处置泄漏，关闭泄漏源，防止事态扩大和加重。

（3）警戒疏散组职责

1）负责事故现场的保护、警戒，组织人员疏散、清点人数，并对周边有影响的单位人员进行疏散；

2）负责公司内的交通管制，确保消防通道畅通，并引导消防，救护车辆等进入；

（4）通讯报警组职责

1）收集所有有关化学品管理的台账和监控信息，对事故区域进行封锁，无关人员禁止入内。

2）负责事故现场人数清点情况告知总指挥，并及时通知周边有影响的单位；

3）收集事故现场信息并及时通知附近的专业医疗机构。

（5）医疗救护组职责

1）在事故发生时，做好抢救灼伤人员的准备工作，对灼伤人员进行简单救治，及时送医院抢救和治疗；

2）负责与专业医疗机构的协调。

（6）后勤保障组职责

1）按照总指挥指令，负责在应急集合点设置应急指挥所（配备桌、椅、等物品）；

2）负责救援现场器材物资的保障工作，负责救援人员的生活保障；

3）完成好总指挥交给的临时任务。

## 处置程序

工作时间内第一发现人发现事故后，应立即向部门负责人报告，部门负责人应根据事故情况作出是否疏散现场员工的决定，并向总指挥或副总指挥报告。

非工作时间内发生事故，第一发现人应立即向现场负责人报告，现场负责人接到报告后，根据事故发生地点、种类、强度和事故可能的危害作出是否疏散员工的决定，并向总指挥或副总指挥报告。

## 处置措施

有限空间应急救援时应严格执行“先通风、再检测、后作业”的原则：

（1）加强通风换气等相应的措施，确保整个救援期间处于安全受控状态检测指标包括氧浓度值、易燃易爆物质（可燃性气体、爆炸性粉尘）浓度值、有毒气体浓度值等。最低限度应检测下列三项：氧浓度（应在19.5-23.5%范围内），易燃/可燃气体浓度（应&lt; 最低爆炸极限的10%），一氧化碳浓度（应&lt;20mg/m3）；

（2）抢险人员要穿戴好必要的劳动防护用品（如正压式空气呼吸器或长管式呼吸器、工作服、工作帽、手套、工作鞋、安全绳等），系好安全带，以防止抢险救援人员受到伤害；

（3）受限空间内抢险人员与外面监护人员应保持通讯联络畅通并确定好联络信号，在抢险人员撤离前，监护人员不得离开监护岗位；

（4）在伤情允许情况下，采取防护措施后将受伤人员救离现场，转移到安全地方进行急救，如果停止呼吸应立即进行人工呼吸，如果心跳停止应立即进行心脏胸外挤压或送往医院。

## 应急保障

（1）抢险人员必须佩戴好个人防护用品进入危险场所进行抢险和救护。

（2）实施抢险救援时应先救人再实施其他抢险。

（3）现场救护与抢险相结合，如没有相应个人防护用品，不得盲目抢险和救护。

（4）现场施救人员应具备相应知识和能力，确保抢险和救治得体有效。

（5）必要时设立警戒区防止无关人员进入危险区。

（6）应急救援装备、物资、药品、消防器材、个体防护用品（具）均配置齐全，并规定定期检查保养，使其经常处于完好可用状态。

（7）及时联系附近抢险救援、消防队、医院，进行抢险救护。
