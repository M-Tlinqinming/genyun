# 03 对标与走查（2026-11-16）

整体方案第 G3 步的产出。前半是 Mobbin 对标：10 个具体问题，每题最多 3 个例子。后半是走查：沿 6 条用户路线重走一遍 Paper 稿，每条最多 5 条建议。

- 建议分两类。「直接进改稿」是界面和交互上的改动，会画进三屏样张和后面的改稿。「问你」会改动已定的流程或新增功能，这里只列出来，等你在确认点 2 一起答。
- 已经写进《00-问题清单》的问题，这里只写编号，不再复述。
- 对标例子都来自 Mobbin 网页端，都是海外产品，只借鉴结构，不照搬文案和样式。链接要登录 Mobbin 才能打开。

## 二、走查：6 条路线

### 1. 客户第一次进来（工作台 → 新建企业 → 新建任务）

| 类 | 建议 | 依据 |
|---|---|---|
| 直接进改稿 | 工作台补「第一次来」的样子：放一张三件事清单（建企业 → 新建任务 → 下载模板填好上传），做完一件勾一件，三件做完清单就收起 | 对标 3；补 6.8 |
| 直接进改稿 | 顶栏左边那几个字不再一直写「客户工作台」（4.9），在进入新建任务的地方把面包屑和侧栏对上（4.4） | 4.4、4.9 |
| 问你 | 「新建企业」并进「新建任务」：在新建任务里选企业时可以直接新建，不再单独走一页。第一次来的客户少走一页 | 改流程 |

### 2. 客户准备资料到提交（准备资料 → 必填核查 → 提交后）

| 类 | 建议 | 依据 |
|---|---|---|
| 直接进改稿 | 向导顶栏加一条阶段条「准备资料 → 专家编制 → 已交付」，和提交后详情页用同一个组件。现在只有提交后才看得到 | 对标 4；4.1 |
| 直接进改稿 | 准备资料页的三张卡不再标「第 1、2、3 步」。三样东西可以按任意顺序准备，改成一份清单，每样显示传了没有 | 对标 1 |
| 直接进改稿 | 必填核查页的「还差这 N 项」按要做的事分成两组：「回表格改 N 项，改完重新上传」和「在这里直接补 N 项」（比如图纸） | 对标 2 |

### 3. 客户拿成果（任务详情 → 成果页 → 成果文档）

| 类 | 建议 | 依据 |
|---|---|---|
| 直接进改稿 | 交付文件行统一成一个组件：客户成果页、次数用完的锁定页、成果文档、专家发布页四处共用，文件名写法统一 | 对标 9；7.10 |
| 直接进改稿 | 次数用完锁住的文件，操作列保留「续费后可下载」灰字，整行不再画成能点的样子；横幅里的「联系耕云续约」是这一屏唯一的主按钮 | 已基本做到，样张里按组件规范落实 |

这条路线的结构没有问题：任务列表有带数字的页签，每行有阶段条和「轮到您」的标记，这些都和对标一致，保留。

## 三、汇总

- 直接进改稿共 16 条，会画进三屏样张（客户端必填核查、专家端任务首页、运营端任务中心）和之后各端的改稿。
- 问你共 3 条，到确认点 2 跟决定包一起问：
  1. 「新建企业」要不要并进「新建任务」
  2. 发布前要不要加「按客户看到的样子预览」
  3. 运营概览和任务中心怎么分工
- 问题清单第十一节里的流程问题照原样保留，这次走查没有新增。
- 不变的地方：客户任务列表、必填核查的缺项定位、审核修订三栏、运营任务中心的「已等 N 天」，这些已经和行业做法一致。
