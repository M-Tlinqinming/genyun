# 验收清单（客户提交、专家处理、运营、官网与账户）

更新：2026-11-02。范围是进度表里已完成的模块，按角色分组。每条写：怎么点、应该看到什么、哪个自动测试覆盖、这次的状态。

- **本次自动测试已过**：这次本机跑「全程验收」测试时一路点到、断言通过（只跑了这一个测试文件，两段各自也能单独跑）。
- **需人工看**：有自动测试覆盖，但这次没有跑；或者是版式、文字、手感，要人眼确认。

全程验收测试分两段：

- **第一段（新客户）**：运营登记一家新组织并登记合同 → 首位管理员从邀请邮件进来设密码 → 新建企业、按提示填写五步 → 提交 → 运营在任务中心看到它待分派。
- **第二段（飞宇全程）**：客户提交飞宇资料 → 运营分派给吴工 → 吴工接单、电话联系客户、专业整理、发一轮事实补件（客户回应、吴工采用）→ 生成三份草稿 → 改一节正文 → 三份 Word 逐份核对 → 审核通过 → 发布交付 V1 → 客户下载三份 Word 并检查 → 客户对这次交付提反馈 → 运营受理、回复并关闭 → 客户在「我的反馈」看到回复。

截图在 `out/m2-acceptance/screens/`，设计稿与实现的并排图在 `out/m2-acceptance/compare/`，下载的三份 Word 在 `out/m2-acceptance/`（这个目录不进仓库，本机跑一次测试就会生成）。

## 发现的问题

1. **三份 Word 里还有 17 处「（待补充）」**（应急预案 14 处，风险评估报告 2 处，应急资源调查报告 1 处）。主要是：
   - 预案编号；
   - 应急经费的年度预算、牵头部门、台账负责人；
   - 培训演练经费、培训档案由谁归档；
   - 周边环境和重大危险源情况；
   - 消防设施布置图、周边环境图、至医院路线图；
   - 重大危险源辨识里「临界量或最大储存量不详」。

   这几项客户填写和专业整理里目前都没有地方填，和「资料先齐再生成」的方向一致：要么在专业整理里补字段，要么在生成前拦下来。没有在本次改。
2. **三份 Word 的结构检查没发现硬伤**。没有空章节，没有没替换的占位符，没有内部编号，表格每行格数一致，文档属性正确。表单里留给手写的横线（日期、签名）是有意保留的。版式、分页、字号还需要打开 Word 人工看一遍。
3. **测试环境的营业执照识别会把客户刚起的企业名称改掉**。新客户新建「惠州验收电器有限公司」后，在第 1 步上传执照，名称被识别结果换成了飞宇（测试环境的识别固定返回飞宇的执照）。正式环境识别的是真执照，以执照为准也说得通，但客户手填的名称被静默换掉，是否要提示「名称已按执照改为…」，需要 Martin 定。
4. **客户组织列表加载时一闪而过「还没有客户组织」和第二个「登记客户组织」按钮**。已在本次修好：加载中不再显示空状态。
5. **「确认采用并生成三份草稿」点下去后要等几秒才跳到生成进度**。按钮有转圈，期间页面没有别的提示。资料多时会更久，可以考虑加一句「正在锁定资料…」。没改。
6. **设计稿对照**（`out/m2-acceptance/compare/`，21 组并排图）。这次没看到新的结构性差异；已知的用词更新（「专家」改为「注安师」等）与设计稿不同，属于已定的改动。注安师任务中心的「客户请求联系」横幅只显示最紧急的一条，后面写「客户请求联系 2」，与设计稿一致。
