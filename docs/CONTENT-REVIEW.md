# 内容打磨对照清单（M2 第 9b 项）

每一轮：拿生成的飞宇三份文档（`npm run sample:plan -w @genyun/api`，输出在 `out/`）逐章对照标准，列出缺漏与错误；改完的写「已改」，要 Martin 定的写「待定」并给建议。Martin 按本清单确认这一轮是否达标；请注安师打分时也用这张清单。

## 对照用的标准

- **主标准**：飞宇手写预案（批注版第 3 页 Martin 对各附件的评价 + 49 条批注）。
- **参考**：世祥塑料、千利电子两家的预案、风险评估结论、应急资源调查报告（10-29 给的案例）。
- **第 1 轮发现**：世祥、千利两家的**应急预案**与我们现在的成稿几乎逐字相同（连写死的「响应时效 30 min / 8-10 min」表、「识别出的 1 项风险因素」这种错句都一样），是旧系统生成后改的，**不能当独立标准**；两家的**风险评估结论**像咨询师手写，可以参考。两家件号写「一、二、五、六」（跳号），我们按实际份数连续编号，是对的。
