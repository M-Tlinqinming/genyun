1. **第一期范围**
   - 先跑通哪条主线：企业自填 → AI 生成 → 专家审核 → 付款 → 下载？

   - 先把设计 token 落成 Ant Design 主题，再做通用组件，最后按页面开发。

   - 要不要用后台模板（如 Ant Design Pro 一类）还是自己搭：讲利弊再推荐。
3. **技术架构**
   - 前端：设计基于 Ant Design 6，React + TypeScript 是自然选择。
   - 后端语言和框架。Word 生成和 AI 调用会影响选择：旧仓库是 TypeScript，Python 的 Word 模板生态也成熟。

4. **中国大陆合规与部署**（以下要点要用最新官方信息核实，不能凭记忆下结论）

   - 大模型：需要用境内可合规提供服务的模型，并了解生成式 AI 服务相关的备案要求。
   - 企业数据加密存储、是否涉及等保。
   - 邮件发信：自有域名 + SPF/DKIM，或境内邮件推送服务，避免进垃圾箱。
5. **收款**
